# 基金基本信息模糊查询

## 查询目的
根据基金简称模糊查询基金的基本信息，包括产品全称、产品简称、产品代码、TA代码、产品类型、子类型和产品状态。

## SQL查询
```sql
SELECT 
    prod_chn_fll_nm_60001 as 产品全称,
    prod_chn_abbr_intr_use_200136 as 产品简称,
    prod_cd as 产品代码,
    ta_cd as TA代码,
    prod_typ_203427 as 产品类型,
    prod_typ_200272 as 子类型,
    prod_stt_cd_200282 as 产品状态
FROM dtlab_r.v_dim_prod_dmns
WHERE prod_chn_abbr_intr_use_200136 LIKE '%关键词%'
```

## 查询说明
此查询从 `dtlab_r.v_dim_prod_dmns` 表中选择与基金简称相关的字段，并通过 `prod_chn_abbr_intr_use_200136` 字段进行模糊匹配，以获取包含特定关键词的基金信息。

## 条件说明
- `prod_chn_abbr_intr_use_200136 LIKE '%关键词%'`: 用于模糊匹配基金简称，其中 `关键词` 需要替换为具体的搜索词。

## 业务场景
在产品管理分析领域，此查询常用于快速查找具有相似名称或特定关键词的基金产品，以便于进一步的分析和管理。

## 问题说明
- 确保 `关键词` 是有效的搜索词，避免使用通配符 `%` 过多导致性能下降。
- 如果查询结果过多，可以考虑增加其他过滤条件，如产品类型或状态。

## 优化建议
- 对 `prod_chn_abbr_intr_use_200136` 字段建立全文索引，提高模糊查询的性能。
- 在生产环境中，建议对查询结果进行分页处理，避免一次性返回大量数据影响系统性能。
