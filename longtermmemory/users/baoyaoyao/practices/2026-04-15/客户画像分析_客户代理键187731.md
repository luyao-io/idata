# 客户画像分析

## 查询目的
通过分析特定客户的交易行为、持仓情况及产品偏好，为营销管理提供数据支持，帮助制定更精准的客户维护策略。

## SQL查询
```sql
WITH customer_info AS (
    SELECT DISTINCT cstm_srrg_key, cstm_fll_nm
    FROM dtlab_r.v_dws_mkt_all_chnn_trd_indx
    WHERE cstm_srrg_key = '187731'
    
    UNION
    
    SELECT DISTINCT cstm_srrg_key, cstm_fll_nm
    FROM dtlab_r.v_dws_mkt_all_chnn_hld_indx
    WHERE cstm_srrg_key = '187731'
),

-- 客户交易行为分析
trading_behavior AS (
    SELECT 
        t.cstm_srrg_key,
        -- 主动交易分析
        SUM(CASE WHEN t.fnd_bsns_typ_cd IN ('122','137') THEN 1 ELSE 0 END) as 主动申购笔数,
        SUM(CASE WHEN t.fnd_bsns_typ_cd IN ('124','138') THEN 1 ELSE 0 END) as 主动赎回笔数,
        SUM(CASE WHEN t.fnd_bsns_typ_cd IN ('122','137') THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 主动申购金额,
        SUM(CASE WHEN t.fnd_bsns_typ_cd IN ('124','138') THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 主动赎回金额,
        -- 定投行为分析
        SUM(CASE WHEN t.fnd_bsns_typ_cd = '139' THEN 1 ELSE 0 END) as 定投申购笔数,
        SUM(CASE WHEN t.fnd_bsns_typ_cd = '139' THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 累计定投金额,
        SUM(CASE WHEN t.fnd_bsns_typ_cd = '163' THEN 1 ELSE 0 END) as 定赎笔数,
        SUM(CASE WHEN t.fnd_bsns_typ_cd = '163' THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 累计定赎金额,
        -- 交易时间分析
        MIN(t.cnfr_dt) as 首次交易日期,
        MAX(t.cnfr_dt) as 最后交易日期
    FROM dtlab_r.v_dws_mkt_all_chnn_trd_indx t
    WHERE t.cstm_srrg_key = '187731'
      AND t.cnfr_dt >= ADD_MONTHS(CURRENT_DATE, -12)
    GROUP BY t.cstm_srrg_key
),

-- 客户持仓分析
holding_analysis AS (
    SELECT 
        h.cstm_srrg_key,
        -- 总持仓情况
        SUM(CASE WHEN h.clnd_dt = (SELECT MAX(clnd_dt) FROM dtlab_r.v_dws_mkt_all_chnn_hld_indx) 
                 THEN h.amnt_blnc_6 ELSE 0 END) as 当前总持仓金额,
        COUNT(DISTINCT CASE WHEN h.clnd_dt = (SELECT MAX(clnd_dt) FROM dtlab_r.v_dws_mkt_all_chnn_hld_indx) 
                           AND h.amnt_blnc_6 > 0 THEN h.mn_prod_cd END) as 当前持仓产品数,
        -- 持仓集中度分析
        MAX(CASE WHEN h.clnd_dt = (SELECT MAX(clnd_dt) FROM dtlab_r.v_dws_mkt_all_chnn_hld_indx) 
                 THEN h.amnt_blnc_6 ELSE 0 END) as 第一大持仓金额,
        MAX(CASE WHEN h.clnd_dt = (SELECT MAX(clnd_dt) FROM dtlab_r.v_dws_mkt_all_chnn_hld_indx) 
                 THEN h.mn_prod_nm END) as 第一大持仓产品,
        -- 历史持仓分析
        COUNT(DISTINCT h.mn_prod_cd) as 历史持仓产品数,
        MIN(h.clnd_dt) as 首次持仓日期
    FROM dtlab_r.v_dws_mkt_all_chnn_hld_indx h
    WHERE h.cstm_srrg_key = '187731'
    GROUP BY h.cstm_srrg_key
),

-- 产品偏好分析
product_preference AS (
    SELECT 
        t.cstm_srrg_key,
        -- 按产品类型统计交易金额
        SUM(CASE WHEN t.prod_typ_200272 = '货币' THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 货币基金交易金额,
        SUM(CASE WHEN t.prod_typ_200272 = '债券' THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 债券基金交易金额,
        SUM(CASE WHEN t.prod_typ_200272 = '混合' THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 混合基金交易金额,
        SUM(CASE WHEN t.prod_typ_200272 = '股票' THEN t.orgn_crrn_cnfr_amnt ELSE 0 END) as 股票基金交易金额,
        -- 最常交易的产品
        MAX(t.mn_prod_nm) as 最常交易产品
    FROM dtlab_r.v_dws_mkt_all_chnn_trd_indx t
    WHERE t.cstm_srrg_key = '187731'
      AND t.cnfr_dt >= ADD_MONTHS(CURRENT_DATE, -12)
    GROUP BY t.cstm_srrg_key
)

-- 综合客户画像
SELECT 
    ci.cstm_fll_nm as 客户姓名,
    tb.主动申购笔数,
    tb.主动赎回笔数,
    ROUND(tb.主动申购金额/10000, 2) as 主动申购金额_万元,
    ROUND(tb.主动赎回金额/10000, 2) as 主动赎回金额_万元,
    tb.定投申购笔数,
    ROUND(tb.累计定投金额/10000, 2) as 累计定投金额_万元,
    tb.定赎笔数,
    ROUND(tb.累计定赎金额/10000, 2) as 累计定赎金额_万元,
    ha.当前总持仓金额/10000 as 当前总持仓金额_万元,
    ha.当前持仓产品数,
    ROUND(ha.第一大持仓金额/10000, 2) as 第一大持仓金额_万元,
    ha.第一大持仓产品,
    ha.历史持仓产品数,
    pp.货币基金交易金额/10000 as 货币基金交易金额_万元,
    pp.债券基金交易金额/10000 as 债券基金交易金额_万元,
    pp.混合基金交易金额/10000 as 混合基金交易金额_万元,
    pp.股票基金交易金额/10000 as 股票基金交易金额_万元,
    pp.最常交易产品,
    tb.首次交易日期,
    tb.最后交易日期,
    ha.首次持仓日期
FROM customer_info ci
LEFT JOIN trading_behavior tb ON ci.cstm_srrg_key = tb.cstm_srrg_key
LEFT JOIN holding_analysis ha ON ci.cstm_srrg_key = ha.cstm_srrg_key
LEFT JOIN product_preference pp ON ci.cstm_srrg_key = pp.cstm_srrg_key
```

## 查询说明
此查询通过多个子查询分别获取客户的个人信息、交易行为、持仓情况和产品偏好，最终将这些信息综合展示在一个结果集中。每个子查询都针对特定的数据表进行分析，并使用条件过滤和聚合函数来提取关键指标。

## 条件说明
- `cstm_srrg_key = '187731'`：指定要分析的客户代理键。
- `t.cnfr_dt >= ADD_MONTHS(CURRENT_DATE, -12)`：限制交易记录的时间范围为过去12个月。
- `h.clnd_dt = (SELECT MAX(clnd_dt) FROM dtlab_r.v_dws_mkt_all_chnn_hld_indx)`：选择最新的持仓日期进行分析。

## 业务场景
适用于市场营销部门对特定客户进行深入分析，了解其交易习惯、投资偏好和资产配置情况，以便制定个性化的服务方案和营销策略。

## 问题说明
- 如果客户在过去的12个月内没有交易记录或持仓记录，相关字段可能显示为空或零值。
- 交易金额和持仓金额单位转换为万元，便于阅读和理解。

## 优化建议
- 可以考虑增加更多的客户属性（如年龄、性别等）以丰富客户画像。
- 对于大数据量的查询，可以考虑使用索引优化查询性能。
- 定期更新数据表中的数据，确保分析结果的时效性。
