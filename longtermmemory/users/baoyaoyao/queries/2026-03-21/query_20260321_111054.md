# 查询产品持有人结构的时间序列

## 查询目的
查询特定时间区间内指定产品的持有人结构（包括个人和机构客户的份额及占比）的时间序列数据。

## SQL查询
```sql
select
a.clnd_dt as 日期,
split_part(a.mn_prod_cd,'+',1) as 主产品代码,
a.mn_prod_nm as 主产品名称,
a.sll_chnn_cd_0 as 渠道代码,
a.sll_chnn_abbr_0 as 渠道名称,
sum(case when a.cstm_typ = '个人' then a.shr_blnc else 0 end) as 个人客户份额,
sum(case when a.cstm_typ = '个人' then a.shr_blnc else 0 end)/nullifzero(sum(a.shr_blnc)) as 个人客户占比,
sum(case when a.cstm_typ in ('机构','产品') then a.shr_blnc else 0 end) as 机构客户份额,
sum(case when a.cstm_typ in ('机构','产品') then a.shr_blnc else 0 end)/nullifzero(sum(a.shr_blnc)) as 机构客户占比
from dtlab_r.v_dws_mkt_all_chnn_hld_indx a
where a.clnd_dt between '2023-09-06' and '2023-09-06'   /*此处修改日期区间*/
and split_part(a.mn_prod_cd,'+',1) in ('000638','100025','511900','000602')   /*此处修改产品范围*/
group by 1,2,3,4,5
```

## 查询说明
此查询从`dtlab_r.v_dws_mkt_all_chnn_hld_indx`表中提取数据，计算每个指定日期、主产品代码、渠道下的个人和机构客户的份额及其占总份额的比例。通过`split_part`函数处理产品代码，以获取主产品代码。

## 条件说明
- **日期区间**：查询的数据范围为2023年9月6日。可根据实际需求调整日期区间。
- **产品范围**：查询的产品代码为'000638', '100025', '511900', '000602'。可根据需要修改或扩展产品列表。

## 业务场景
此查询适用于市场营销管理分析，帮助了解不同时间段内各产品在不同销售渠道上的持有人结构变化，为市场策略调整提供数据支持。

## 问题说明
- 确保日期格式正确无误，避免因日期格式错误导致查询失败。
- 检查产品代码是否准确，确保查询结果的准确性。

## 优化建议
- 如果查询涉及大量数据，考虑使用分区表或索引优化查询性能。
- 定期检查和更新产品代码列表，确保数据的时效性和准确性。
- 对于频繁使用的查询，可以考虑创建视图或存储过程，简化日常操作。
