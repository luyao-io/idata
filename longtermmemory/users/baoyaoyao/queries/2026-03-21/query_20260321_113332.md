# 根据基金代码或债券代码（名称）查询某一时点的持仓债券信息

## 查询目的
根据基金代码或债券代码（名称）查询某一时点的持仓债券信息，以便于投资组合分析和管理。

## SQL查询
```sql
/*名称：根据基金代码或债券代码（名称）查询某一时点的持仓债券信息*/
/*说明：由于表的权限不同，可能得到的产品结果范围不同，请注意适用的基金业务类型*/
/*编写人员：刘雨*/
/*联系方式：*/
/*编写日期：20241213*/
WITH tmp_rate AS
 (SELECT s_info_windcode
        ,rate /*证券属性key */
    FROM (SELECT a10.s_info_windcode
                ,a10.rate
                ,TO_DATE(a10.change_dt, 'YYYYMMDD') AS start_dt
                ,TO_DATE(to_char(COALESCE(lead(a10.change_dt) OVER(PARTITION BY a10.s_info_windcode ORDER BY a10.change_dt), '30001231')), 'YYYYMMDD') AS end_dt
            FROM dtlab_r.v_s034_wfdb_floatingcouponsrate a10 /*中国浮息债票面利率变动*/
          UNION
          SELECT a10.s_info_windcode
                ,a10.rate
                ,TO_DATE(a10.start_dt, 'YYYYMMDD') AS start_dt
                ,COALESCE(TO_DATE(a10.end_dt, 'YYYYMMDD') + 1
                         ,TO_DATE(to_char(COALESCE(lead(a10.start_dt) OVER(PARTITION BY a10.s_info_windcode ORDER BY a10.start_dt), '30001231'))
                                 ,'YYYYMMDD')) AS end_dt
            FROM dtlab_r.v_s034_wfdb_optionembeddedbondrate a10 /*中国含权债票面利率变动*/
          ) a10
          /*更改拉链表生效日期*/
   WHERE start_dt <= DATE('20241212') AND end_dt > DATE('20241212')),
tmp_rate2 AS
 (SELECT c20.s_info_windcode /*证券wind代码*/
        ,COALESCE(c70.rate, c20.b_info_couponrate, c20.b_tendrst_referyield) / 100 AS b_info_couponrate /*票面利率*/
    FROM dtlab_r.v_s081_pdata_cbonddescription c20 /*中国国债券基本资料*/
    LEFT JOIN tmp_rate c70
      ON c20.s_info_windcode = c70.s_info_windcode),
tmp_rate3 AS
 (SELECT t1.scrt_wind_cd
        ,t1.prod_cd
        ,t2.b_anal_ytm /*到期收益率*/
    FROM dtlab_r.v_dws_inv_prod_indx_d2 t1
    LEFT JOIN dtlab_r.v_s034_wfdb_cbondvaluation t2
      ON t1.scrt_wind_cd = t2.s_info_windcode AND
         t1.indx_vl = DATE(t2.trade_dt) AND
         t1.indx_id = 'drvi_scrt_mst_rcnt_prch_dt_td_00' /*最近买入日期*/ AND
         /*输入日期参数*/
         t1.dt = '20241212'
   WHERE t2.s_info_windcode IS NOT NULL),
tmp_invs_clss AS
 (SELECT a10.prod_srrg_key
        ,a10.scrt_srrg_key
        ,transpose(a10.prod_srrg_key || '-' || a10.scrt_srrg_key, a20.enmr_nm, ',') OVER(PARTITION BY a10.prod_srrg_key, a10.scrt_srrg_key ORDER BY a20.enmr_nm)
    FROM dtlab_r.v_dwd_inv_prod_stnd_vltn a10
    LEFT JOIN dtlab_r.v_para_stnd_cd a20
      ON a10.invs_clss_cd = a20.enmr_cd AND
         a20.enmr_fld = 'invs_clss_cd'
   WHERE vltn_dt = '20241212' AND  /*输入日期*/
        a10.prod_cd = '000107' AND /*输入产品代码*/
         scrt_typ_cd = 'ZQ' AND
         acct_proj_cd = 'ZQTZ_CB'),
tmp_yld AS
 (SELECT b10.clnd_dt
        ,b20.main_code
        ,b20.b_anal_yield_cnbd
        ,b20.b_anal_modidura_cnbd
        ,b20.b_anal_matu_cnbd
    FROM dtlab_r.v_dim_clnd_dt_dmns b10
    LEFT JOIN (SELECT trade_dt
                    ,COALESCE(lag(trade_dt) OVER(PARTITION BY main_code ORDER BY trade_dt DESC), DATE('30001231')) lag_trade_dt
                    ,main_code
                    ,b_anal_yield_cnbd
                    ,b_anal_modidura_cnbd
                    ,b_anal_matu_cnbd
                FROM (SELECT DATE(trade_dt) trade_dt
                            ,main_code
                            ,b_anal_yield_cnbd
                            ,b_anal_modidura_cnbd
                            ,b_anal_matu_cnbd
                            ,ROW_NUMBER() OVER(PARTITION BY trade_dt, main_code ORDER BY b_anal_matu_cnbd) rk
                        FROM dtlab_r.v_s081_pdata_cbondanalysiscnbd_b08
                        /*输入日期参数*/
                       WHERE DATE(trade_dt) BETWEEN DATE('20241212') - 20 AND DATE('20241212') + 20) a
               WHERE rk = 1) b20
      ON b10.clnd_dt >= b20.trade_dt AND
         b10.clnd_dt < b20.lag_trade_dt
   WHERE b10.clnd_dt BETWEEN DATE('20241212') - 20 AND DATE('20241212'))
SELECT a10.prod_cd AS "基金代码"
      ,a10.prod_chn_fll_nm_60001 AS "基金名称"
      ,a10.bnd_scrt_wind_cd AS "债券编号"
      ,a10.bnd_scrt_chn_abbr AS "债券名称"
      ,a10.fnct_crrn_hldn_mkt_vl AS "市值"
      ,a10.hldn_qntt AS "数量"
      ,a10.hldn_cst_fnct_crrn AS "成本"
      ,a10.fnct_crrn_mkt_vl_rt AS "占基金净值比例"
      ,a10.wind_nwst_dbt_rtng AS "债项评级（万得最新）"
      ,a10.wind_mn_rtng AS "主体评级（万得主体）"
      ,a10.vl_dt AS "起息日期"
      ,a10.mtrt_dt AS "到期日期"
      ,COALESCE(a30.b_anal_ytm / 100, a20.b_info_couponrate) AS "买入收益率"
      ,COALESCE(a10.wind_lvl_2_brd_nm, a10.wind_lvl_1_brd_nm) AS "万得二级分类"
      ,a10.mdfd_drtn AS "修正久期"
      ,a10.rsdl_mtrt_yr AS "剩余期限（年）"
      ,a10.issr_nm AS "发行人"
      ,REPLACE(a10.scrt_dtl_typ, '债券品种_', '') AS "债券类别"
      ,a10.cpn_rt AS "票面利率"
      ,'债项' || a10.intr_dbt_rtng AS "内部债项评级"
      ,'主体' || a10.intr_mn_rtng AS "内部主体评级"
      ,a10.isin_cd AS "ISIN码"
      ,a10.rskm_dbt_rtng AS "债项评级（风控）"
      ,a10.rskm_mn_rtng AS "主体评级（风控）"
      ,COALESCE(round(a10.stnd_scrt_rt * 100, 2), 0) AS "标准券占比%"
      ,a10.i9_rl_hldn_mdfd_mkt_vl_fnct_crrn AS "I9市值"
      ,a10.i9_rl_hldn_mdfd_mkt_vl_fnct_crrn_net_vl_rt AS "I9占基金净值比例"
      ,a10.buy_yld_to_mtrt_fnnc_engn / 100 AS "买入到期收益率（金工组）"
      ,a10.frst_buy_dt AS "首次买入日期"
      ,a10.rcnt_buy_dt AS "最近买入日期"
      ,a10.cnbd_imp_rtng as "中债隐含评级"
      ,a40.group_label AS "投资类别"
      ,round(a50.b_anal_yield_cnbd / 100, 2) AS "估价收益率"
      ,a50.b_anal_modidura_cnbd as "行权久期"
  FROM dtlab_r.v_dwm_inv_prod_invs_bnd_hldn_dtls a10
  LEFT JOIN tmp_rate2 a20
    ON a10.bnd_scrt_wind_cd = a20.s_info_windcode
  LEFT JOIN tmp_rate3 a30
    ON a10.bnd_scrt_wind_cd = a30.scrt_wind_cd AND
       a10.prod_cd = a30.prod_cd
  LEFT JOIN tmp_invs_clss a40
    ON a10.prod_srrg_key = a40.prod_srrg_key AND
       a10.bnd_scrt_srrg_key = a40.scrt_srrg_key
  LEFT JOIN tmp_yld a50
    ON a10.bnd_scrt_srrg_key = a50.main_code AND
       a50.clnd_dt = '20241212'
 WHERE  a10.prod_cd = '000107' AND /*输入产品代码*/
       a10.vltn_dt = '20241212'   /*输入日期*/
 ORDER BY a10.vltn_dt
         ,a10.prod_cd
         ,a10.prod_chn_fll_nm_60001
         ,a10.bnd_scrt_wind_cd
```

## 查询说明
此查询用于根据基金代码或债券代码（名称）查询某一时点的持仓债券信息。查询结果包括基金代码、基金名称、债券编号、债券名称、市值、数量、成本、占基金净值比例等详细信息。

## 条件说明
- `prod_cd`：基金代码，例如 '000107'。
- `vltn_dt`：查询日期，例如 '20241212'。

## 业务场景
此查询适用于投资组合分析，帮助基金经理和分析师了解特定时点的持仓债券情况，以便进行投资决策和风险管理。

## 问题说明
- 确保输入的基金代码和查询日期正确无误。
- 由于表的权限不同，查询结果可能因权限限制而有所不同。

## 优化建议
- 确保所有涉及的表和视图已建立适当的索引，以提高查询性能。
- 定期检查和优化数据库统计信息，确保查询优化器能够选择最优的执行计划。
- 考虑使用分区表来提高大数据量下的查询效率。
