# 查询指定净值日期的全产品转融通交易明细信息

## 查询目的
查询指定净值日期的全产品转融通交易明细信息，以便进行投资组合分析。

## SQL查询
```sql
/* 名称：查询指定净值日期的全产品转融通交易明细信息*/
/* 说明：由于表权限不同，可能得到的产品结果范围不同*/
/* 编写人员：蔡济烈*/
/* 联系方式：021-20363171 18001812349*/
/* 编写日期：20230908*/
select
  a.prod_cd 产品代码,
  a.scrt_wind_cd 股票代码,
  a.scrt_chn_abbr 股票名称,
  a.trd_mkt_cd 交易市场代码,
  b.enmr_nm 交易市场,
  a.dl_qntt 交易数量,
  a.fnct_crrn_scrt_lnd_cst "借券费用（折人民币）", 
  a.trd_dt 回购起始日期,
  a.mtrt_dt 回购到期日期  
from
 dtlab_r.v_dwm_inv_rfnn_invs_trd_flw a
left join dtlab_r.v_para_stnd_cd b on  b.enmr_fld='trd_mkt_cd' and b.enmr_cd=a.trd_mkt_cd
where
  a.trd_dt <= '20230907' /*净值日期*/  AND
  a.mtrt_dt >  '20230907' /*净值日期*/
```

## 查询说明
此查询用于获取指定净值日期的全产品转融通交易明细信息。通过连接`dtlab_r.v_dwm_inv_rfnn_invs_trd_flw`和`dtlab_r.v_para_stnd_cd`两个视图，可以获取到包括产品代码、股票代码、股票名称、交易市场代码、交易市场、交易数量、借券费用、回购起始日期和回购到期日期等详细信息。

## 条件说明
- `a.trd_dt <= '20230907'`：交易起始日期小于或等于指定的净值日期。
- `a.mtrt_dt > '20230907'`：回购到期日期大于指定的净值日期。

## 业务场景
此查询适用于投资组合分析中的转融通交易监控，帮助分析师了解特定日期内所有产品的转融通交易情况，以便进行风险管理和投资决策。

## 问题说明
- 由于表权限的不同，不同的用户可能获取到的产品结果范围会有所不同。
- 确保查询中使用的日期格式正确，并且与数据库中的日期格式一致。

## 优化建议
- 对于频繁执行的查询，考虑创建索引以提高查询性能，特别是对`trd_dt`和`mtrt_dt`字段。
- 定期检查和更新表权限，确保数据访问的安全性和合规性。
- 如果查询结果集较大，可以考虑分页查询或使用数据分区技术来优化查询效率。
