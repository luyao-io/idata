# 查询指定日期区间、指定产品的规模份额每日变化趋势

## 查询目的
查询指定日期区间内，指定产品的规模份额每日变化趋势。

## SQL查询
```sql
/* 名称：查询指定日期区间、指定产品的规模份额每日变化趋势*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/
SELECT clnd_dt 自然日期
       ,split_part(mn_prod_cd, '+', 1) 主基金代码
       ,mn_prod_nm 主基金名称
       ,SUM(shr_blnc) 保有份额
       ,SUM(amnt_blnc_7) 保有金额
   FROM DTLAB_R.v_dws_mkt_all_chnn_hld_indx
  WHERE clnd_dt BETWEEN '20230831' AND '20230910' AND --自然日期
        split_part(mn_prod_cd, '+', 1) = '161005' --主基金产品
  GROUP BY clnd_dt
          ,split_part(mn_prod_cd, '+', 1)
          ,mn_prod_nm
  ORDER BY clnd_dt ASC
```

## 查询说明
此查询用于分析特定日期区间内，指定产品的规模份额和保有金额的变化情况。通过该查询可以了解产品在市场上的表现趋势。

## 条件说明
- `clnd_dt BETWEEN '20230831' AND '20230910'`：指定查询的日期区间为2023年8月31日至2023年9月10日。
- `split_part(mn_prod_cd, '+', 1) = '161005'`：指定查询的主基金产品代码为161005。

## 业务场景
此查询适用于市场营销管理分析，帮助市场分析师或产品经理了解特定产品在市场中的表现，以便做出相应的市场策略调整。

## 问题说明
- 由于表的权限不同，可能得到的产品结果范围不同。
- 确保查询的日期格式正确，并且与数据库中存储的日期格式一致。

## 优化建议
- 如果查询性能不佳，可以考虑对`clnd_dt`和`mn_prod_cd`字段建立索引。
- 定期检查和更新数据表的统计信息，以提高查询优化器的选择性估计。
- 对于频繁使用的查询，可以考虑创建视图或物化视图来加速查询响应时间。
