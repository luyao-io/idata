# 查询产品持有人结构的时间序列

## 查询目的
查询一定时间区间内产品持有人结构的时间序列，以便于分析不同渠道和产品在特定时间段内的个人与机构客户的持有情况及其占比。

## SQL查询
```sql
/* 名称：查询一定时间区间内产品持有人结构的时间序列*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：赵阳*/
/* 联系方式：021-20513209*/
/* 编写日期：20230908*/
select
a.clnd_dt 日期
,split_part(a.mn_prod_cd,'+',1) 主产品代码
,a.mn_prod_nm 主产品名称
,a.sll_chnn_cd_0 渠道代码 
,a.sll_chnn_abbr_0 渠道名称
,sum(case when a.cstm_typ = '个人' then a.shr_blnc else 0 end) 个人客户份额
,sum(case when a.cstm_typ = '个人' then a.shr_blnc else 0 end)/nullifzero(sum(a.shr_blnc)) 个人客户占比
,sum(case when a.cstm_typ in ('机构','产品') then a.shr_blnc else 0 end) 机构客户份额
,sum(case when a.cstm_typ in ('机构','产品') then a.shr_blnc else 0 end)/nullifzero(sum(a.shr_blnc)) 机构客户占比
from dtlab_r.v_dws_mkt_all_chnn_hld_indx a
where a.clnd_dt between '2023-09-06' and '2023-09-06'   /*此处修改日期区间*/
and split_part(a.mn_prod_cd,'+',1) in ('000638','100025','511900','000602')   /*此处修改产品范围*/
group by 1,2,3,4,5
```

## 查询说明
此查询用于获取指定日期区间内，特定产品的持有人结构数据，包括个人客户和机构客户的持有份额及占比。通过此查询可以了解不同渠道下各产品的市场分布情况。

## 条件说明
- **日期区间**：`a.clnd_dt between '2023-09-06' and '2023-09-06'`，用户可以根据需要调整日期区间以获取不同时间段的数据。
- **产品范围**：`split_part(a.mn_prod_cd,'+',1) in ('000638','100025','511900','000602')`，用户可以根据需求选择不同的产品代码进行查询。

## 业务场景
此查询适用于市场营销管理分析，特别是对于产品销售策略的制定、市场趋势的分析以及客户群体的细分等方面具有重要参考价值。

## 问题说明
- 如果查询结果为空，可能是由于所选日期区间或产品范围内没有相关数据，或者当前用户没有访问指定表的权限。
- `nullifzero`函数用于避免除数为零的情况，确保计算的准确性。
