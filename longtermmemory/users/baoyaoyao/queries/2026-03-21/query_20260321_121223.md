# 查询指定净值日期的银行间回购交易质押券明细信息

## 查询目的
查询指定净值日期的银行间回购交易质押券明细信息，以便进行投资组合分析。

## SQL查询
```sql
/* 名称：查询指定净值日期的银行间回购交易质押券明细信息*/
/* 说明：由于表权限不同，可能得到的产品结果范围不同*/
/* 编写人员：蔡济烈*/
/* 联系方式：021-20363171 18001812349*/
/* 编写日期：20230908*/

select  
a.prod_cd 产品代码,
  c.scrt_cd 回购代码,
  c.ipo_mkt_cd 交易市场代码,
  b1.enmr_nm 交易市场,
   a.dl_id 成交编号,
   b.wind_cd 质押券编号,
   b.scrt_chn_abbr 质押券 ,
   b.scrt_dtl_typ 质押券类型,
   pldg_qntt 质押数量,
   pldg_rt 质押比例
  from dtlab_r.v_dwm_inv_rprc_invs_trd_pldg_bnd_dtls a
left join dtlab_r.v_dim_scrt_dmns b on a.pldg_bnd_scrt_srrg_key = b.scrt_srrg_key 
left join dtlab_r.v_dim_scrt_dmns c on a.rprc_scrt_srrg_key = c.scrt_srrg_key 
left join dtlab_r.v_para_stnd_cd b1 on  b1.enmr_fld='trd_mkt_cd' and b1.enmr_cd=c.ipo_mkt_cd

where
  a.trd_dt <= '20230907' /*净值日期*/  AND
  a.mtrt_dt >  '20230907' /*净值日期*/
```

## 查询说明
此查询用于获取指定净值日期（例如2023年9月7日）的银行间回购交易质押券的详细信息。通过连接多个视图，可以获取到包括产品代码、回购代码、交易市场代码、成交编号、质押券编号、质押券类型、质押数量和质押比例等信息。

## 条件说明
- `a.trd_dt <= '20230907'`：交易日期小于或等于指定的净值日期。
- `a.mtrt_dt > '20230907'`：到期日期大于指定的净值日期。

## 业务场景
此查询适用于投资组合分析中的银行间回购交易质押券管理，帮助分析师了解特定日期的质押券情况，以便做出更准确的投资决策。

## 问题说明
- 表权限不同可能导致查询结果范围的不同。
- 需要确保所有涉及的表和字段在执行查询时具有正确的访问权限。

## 优化建议
- 确保索引在经常用于过滤条件的列上（如`trd_dt`和`mtrt_dt`），以提高查询性能。
- 定期检查和维护数据库统计信息，以确保查询优化器能够选择最佳的执行计划。
- 如果查询结果集较大，考虑使用分页或限制返回的行数，以减少内存消耗和提高响应速度。
