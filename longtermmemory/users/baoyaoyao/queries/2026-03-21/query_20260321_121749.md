# 查询数仓产品级指标表中的指标对应值

## 查询目的
查询数仓中产品级指标表中的特定指标值，包括但不限于组合净资产、组合收益率、组合投资收益、分红等。

select

## 查询说明
1. 本查询用于从数仓中提取特定产品的指标值。
2. 可以通过修改 `a.indx_id` 的值来选择不同的指标进行查询。
3. 通过 `b.prod_lvl` 和 `b.prod_typ_203427` 等条件，可以进一步筛选出特定类型或层级的产品。
4. 如果需要查询所有可用的指标，可以先执行注释中的 SQL 语句。

## 条件说明
- `a.indx_id`: 指标ID，例如 'drvi_fnd_mltrtrn01_1d_00' 表示当日组合收益率（自然日）。
- `b.prod_lvl`: 产品层级，码值对应关系为 {0:母基金, 1:子基金}。
- `b.prod_typ_203427`: 产品类型，例如 '养老金'、'养老保障' 等。
- `a.prod_cd`: 组合代码，用于筛选特定的组合。

## 业务场景
本查询适用于投资组合分析，特别是需要定期监控和分析各类投资产品的关键指标时。通过该查询，可以快速获取指定产品的特定指标值，帮助投资经理和分析师做出更准确的决策。

## 问题说明
- 如果查询结果为空，请检查 `a.indx_id` 是否正确，以及是否有权限访问相关数据。
- 如果需要查询多个指标，可以在 `a.indx_id` 中使用逗号分隔多个指标ID。
