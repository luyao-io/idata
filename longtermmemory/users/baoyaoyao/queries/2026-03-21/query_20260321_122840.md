# 查询指定日期区间内，IPO产品的客户分布情况分析

## 查询目的
查询指定日期区间内，IPO产品的客户分布情况，以便进行市场管理与分析。

## SQL查询
```sql
/* 名称：查询指定日期区间内，IPO产品的客户分布情况分析*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：赵阳*/
/* 联系方式：021-20513209*/
/* 编写日期：20250731*/

with tmp as(
select 
a.mn_prod_cd,
a.mn_prod_nm,
a.sll_chnn_abbr_0,
a.cstm_srrg_key,
sum(a.cnfr_shr) cnfr_shr,
case 
    when sum(a.cnfr_shr) < 1000 then '1000以下'
    when sum(a.cnfr_shr) >= 1000 and sum(a.cnfr_shr) < 10000 then '1000-10000'
    when sum(a.cnfr_shr) >= 10000 and sum(a.cnfr_shr) < 50000 then '10000-50000'
    when sum(a.cnfr_shr) >= 50000 and sum(a.cnfr_shr) < 100000 then '50000-100000'
    when sum(a.cnfr_shr) >= 100000 and sum(a.cnfr_shr) < 500000 then '100000-500000'
    when sum(a.cnfr_shr) >= 500000 and sum(a.cnfr_shr) < 1000000 then '500000-1000000'
    else '100W以上' 
end flag
from DTLAB_R.v_dws_mkt_all_chnn_trd_indx a
where a.cnfr_dt between '20250101' and '20250731' --限制日期区间
and a.ta_cd <> 'ETF'
and a.fnd_bsns_typ_cd = '130' --用成立流水数据更准确
and a.prod_typ_203427 IN ('公募')
group by 1,2,3,4
)

select
split_part(a.mn_prod_cd,'+',1) 基金代码,
a.mn_prod_nm 基金名称,
a.sll_chnn_abbr_0 渠道名称,
sum(case when a.flag = '1000以下' then a.cnfr_shr else 0 end) 规模_1000以下,
sum(case when a.flag = '1000-10000' then a.cnfr_shr else 0 end) 规模_1000至10000,
sum(case when a.flag = '10000-50000' then a.cnfr_shr else 0 end) 规模_10000至50000,
sum(case when a.flag = '50000-100000' then a.cnfr_shr else 0 end) 规模_50000至100000,
sum(case when a.flag = '100000-500000' then a.cnfr_shr else 0 end) 规模_100000至500000,
sum(case when a.flag = '500000-1000000' then a.cnfr_shr else 0 end) 规模_500000至1000000,
sum(case when a.flag = '100W以上' then a.cnfr_shr else 0 end) 规模_100W以上,
count(distinct case when a.flag = '1000以下' then a.cstm_srrg_key else null end) 客户数_1000以下,
count(distinct case when a.flag = '1000-10000' then a.cstm_srrg_key else null end) 客户数_1000至10000,
count(distinct case when a.flag = '10000-50000' then a.cstm_srrg_key else null end) 客户数_10000至50000,
count(distinct case when a.flag = '50000-100000' then a.cstm_srrg_key else null end) 客户数_50000至100000,
count(distinct case when a.flag = '100000-500000' then a.cstm_srrg_key else null end) 客户数_100000至500000,
count(distinct case when a.flag = '500000-1000000' then a.cstm_srrg_key else null end) 客户数_500000至1000000,
count(distinct case when a.flag = '100W以上' then a.cstm_srrg_key else null end) 客户数_100W以上
from tmp a
group by 1,2,3

union all

select
split_part(a.mn_prod_cd,'+',1) 基金代码,
a.mn_prod_nm 基金名称,
'全渠道' 渠道名称,
sum(case when a.flag = '1000以下' then a.cnfr_shr else 0 end) 规模_1000以下,
sum(case when a.flag = '1000-10000' then a.cnfr_shr else 0 end) 规模_1000至10000,
sum(case when a.flag = '10000-50000' then a.cnfr_shr else 0 end) 规模_10000至50000,
sum(case when a.flag = '50000-100000' then a.cnfr_shr else 0 end) 规模_50000至100000,
sum(case when a.flag = '100000-500000' then a.cnfr_shr else 0 end) 规模_100000至500000,
sum(case when a.flag = '500000-1000000' then a.cnfr_shr else 0 end) 规模_500000至1000000,
sum(case when a.flag = '100W以上' then a.cnfr_shr else 0 end) 规模_100W以上,
count(distinct case when a.flag = '1000以下' then a.cstm_srrg_key else null end) 客户数_1000以下,
count(distinct case when a.flag = '1000-10000' then a.cstm_srrg_key else null end) 客户数_1000至10000,
count(distinct case when a.flag = '10000-50000' then a.cstm_srrg_key else null end) 客户数_10000至50000,
count(distinct case when a.flag = '50000-100000' then a.cstm_srrg_key else null end) 客户数_50000至100000,
count(distinct case when a.flag = '100000-500000' then a.cstm_srrg_key else null end) 客户数_100000至500000,
count(distinct case when a.flag = '500000-1000000' then a.cstm_srrg_key else null end) 客户数_500000至1000000,
count(distinct case when a.flag = '100W以上' then a.cstm_srrg_key else null end) 客户数_100W以上
from tmp a
group by 1,2,3
```

## 查询说明
此查询用于分析指定日期区间内IPO产品的客户分布情况。通过不同的规模区间（如1000以下、1000-10000等）来统计每个基金在不同渠道下的客户数量和确认份额。

## 条件说明
- `cnfr_dt`：确认日期，限定在2025年1月1日至2025年7月31日之间。
- `ta_cd`：交易代码，排除ETF产品。
- `fnd_bsns_typ_cd`：基金业务类型代码，限定为130，表示使用成立流水数据。
- `prod_typ_203427`：产品类型，限定为“公募”。

## 业务场景
此查询适用于市场营销部门，帮助分析IPO产品在不同渠道的客户分布情况，以便制定更有效的市场策略和客户维护计划。

## 问题说明
- 表的权限不同可能导致查询结果的范围不同。
- 确认日期的范围可以根据实际需要调整。

## 优化建议
- 可以考虑增加索引以提高查询性能，特别是在`cnfr_dt`、`ta_cd`、`fnd_bsns_typ_cd`和`prod_typ_203427`字段上。
- 如果数据量非常大，可以考虑使用分区表来进一步优化查询性能。
- 对于频繁使用的查询，可以考虑创建视图或物化视图来减少重复计算。
