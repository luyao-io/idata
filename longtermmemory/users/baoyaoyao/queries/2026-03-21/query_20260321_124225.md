# 查询指定自然日期和产品类型，机构、产品有效客户数的增减情况

## 查询目的
查询指定自然日期和产品类型下，机构和产品的有效客户数在两个时间点（期初和期末）的变化情况。

## SQL查询
```sql
/* 名称：查询指定自然日期和产品类型，机构、产品有效客户数的增减情况*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/
WITH tmp AS
 (SELECT prod_cd
        ,cstm_typ
        ,COUNT(DISTINCT aftr_mrg_cstm_id) num
    FROM DTLAB_R.v_dws_mkt_all_chnn_hld_indx
   WHERE clnd_dt = '20230731' AND  --期初日期
         cstm_typ IN ('机构', '产品') AND
         prod_typ_203427 = '公募' AND
         shr_blnc > 0
   GROUP BY prod_cd
            ,cstm_typ),
tmp_1 AS
 (SELECT prod_cd
        ,cstm_typ
        ,COUNT(DISTINCT aftr_mrg_cstm_id) num
    FROM DTLAB_R.v_dws_mkt_all_chnn_hld_indx
   WHERE clnd_dt = '20230831' AND  --期末日期
         cstm_typ IN ('机构', '产品') AND
         prod_typ_203427 = '公募' AND
         shr_blnc > 0
   GROUP BY prod_cd
           ,cstm_typ)
SELECT a1.prod_cd AS '产品代码'
      ,a2.cstm_typ AS '客户类型'
      ,a3.prod_chn_abbr_intr_use_200136 AS '产品名称'
      ,a1.num AS '本期末'
      ,a2.num AS '上期末'
      ,a1.num - COALESCE(a2.num, 0) AS '本期末与上期末相差'
  FROM tmp_1 a1
  LEFT JOIN tmp a2
    ON a1.prod_cd = a2.prod_cd AND
       a1.cstm_typ = a2.cstm_typ
  LEFT JOIN DTLAB_R.v_dim_prod_dmns a3
    ON a3.prod_lvl = '1' AND
       a1.prod_cd = a3.prod_cd
 ORDER BY a1.num - COALESCE(a2.num, 0) ASC;
```

## 查询说明
此查询用于分析特定时间段内（例如2023年7月31日至2023年8月31日），特定产品类型（如“公募”）下的机构和产品的有效客户数的变化情况。通过比较期初和期末的有效客户数，可以了解这些产品在这段时间内的市场表现。

## 条件说明
- `clnd_dt`：指定的自然日期，分别用于期初（20230731）和期末（20230831）的数据查询。
- `cstm_typ`：客户类型，限定为“机构”和“产品”。
- `prod_typ_203427`：产品类型，限定为“公募”。
- `shr_blnc`：份额余额，要求大于0，表示有效的客户持有量。

## 业务场景
此查询适用于市场营销管理分析，特别是对于需要监控特定时间段内产品表现和客户增长情况的场景。通过该查询，管理层可以及时了解哪些产品在市场上的表现较好，哪些产品需要进一步的市场推广或策略调整。

## 问题说明
- 如果某些产品在期初没有数据，则其“上期末”字段将显示为0。
- 表的权限可能影响最终查询结果的完整性和准确性。

## 优化建议
- 增加对不同产品类型的动态选择支持，以便于更灵活地进行市场分析。
- 考虑增加更多的日期范围选项，以适应不同的分析需求。
- 对于大数据量的查询，考虑使用分区表或索引优化查询性能。
