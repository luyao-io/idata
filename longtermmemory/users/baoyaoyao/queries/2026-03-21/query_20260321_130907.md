# A股申万行业2021版本查询

## 查询目的
查询A股市场中属于申万行业分类2021版的所有股票及其对应的行业信息，包括一级、二级、三级和四级行业名称及别名。

## SQL查询
```sql
--申万行业2021A股对应查询
select '申万2021' as inds_clas,
       A.S_INFO_WINDCODE,
       lpad(substr(A.S_INFO_WINDCODE, 0, instr(A.S_INFO_WINDCODE, '.') - 1), 5, '0') as STOCK_CODE,
       B1.Industriesalias as INDUSTRIESALIAS1,
       B1.INDUSTRIESNAME as INDUSTRIESNAME1,
       B2.Industriesalias as INDUSTRIESALIAS2,
       B2.INDUSTRIESNAME as INDUSTRIESNAME2,
       B3.Industriesalias as INDUSTRIESALIAS3,
       B3.INDUSTRIESNAME as INDUSTRIESNAME3,
       B4.Industriesalias as INDUSTRIESALIAS4,
       B4.INDUSTRIESNAME as INDUSTRIESNAME4
  from dtlab_r.v_s081_pdata_ashareswnindustriesclass A
  left join dtlab_r.v_s081_pdata_ashareindustriescode B4
    on substr(A.sw_ind_code, 1, 10) = substr(b4.INDUSTRIESCODE, 1, 10)
   and b4.LEVELNUM = 5
   and b4.INDUSTRIESCODE like '76%'
  left join dtlab_r.v_s081_pdata_ashareindustriescode B3
    on substr(A.sw_ind_code, 1, 8) = substr(b3.INDUSTRIESCODE, 1, 8)
   and b3.LEVELNUM = 4
   and b3.INDUSTRIESCODE like '76%'
  left join dtlab_r.v_s081_pdata_ashareindustriescode B2
    on substr(A.sw_ind_code, 1, 6) = substr(b2.INDUSTRIESCODE, 1, 6)
   and b2.LEVELNUM = 3
   and b2.INDUSTRIESCODE like '76%'
  left join dtlab_r.v_s081_pdata_ashareindustriescode B1
    on substr(A.sw_ind_code, 1, 4) = substr(b1.INDUSTRIESCODE, 1, 4)
   and b1.LEVELNUM = 2
   and b1.INDUSTRIESCODE like '76%'
 where A.CUR_SIGN = 1
   and A.sw_ind_code like '76%';
```

## 查询说明
此查询从`dtlab_r.v_s081_pdata_ashareswnindustriesclass`表中选择当前有效的（`CUR_SIGN = 1`）且行业代码以`76`开头的A股股票，并通过多个左连接操作，将这些股票与不同级别的行业代码表进行关联，获取每个股票的一级至四级行业信息。

## 条件说明
- `A.CUR_SIGN = 1`: 筛选当前有效的行业分类记录。
- `A.sw_ind_code like '76%'`: 筛选行业代码以`76`开头的记录，表示特定的行业分类。
- `B1.LEVELNUM = 2`, `B2.LEVELNUM = 3`, `B3.LEVELNUM = 4`, `B4.LEVELNUM = 5`: 分别匹配一级、二级、三级和四级行业代码。

## 业务场景
适用于需要分析A股市场中特定行业（如申万行业2021版）内各股票分布情况的业务需求，帮助投资者或分析师了解特定行业的市场构成。

## 问题说明
- 如果查询结果为空，可能是因为没有符合筛选条件的数据，或者数据表中的数据不完整。
- 行业代码前缀`76`可能需要根据实际业务需求调整。

## 优化建议
- 考虑在`sw_ind_code`字段上建立索引，以提高查询性能。
- 定期检查并更新行业代码表，确保数据的准确性和完整性。
- 对于频繁使用的查询，可以考虑创建视图或物化视图来加速查询响应时间。
