# 查询指定申请日期的公募产品申购、赎回，净申购交易数据

## 查询目的
查询指定申请日期的公募产品申购、赎回，以及净申购的交易数据，以便进行营销管理分析。

## SQL查询
```sql
/* 名称：查询指定申请日期的公募产品申购、赎回，净申购交易数据*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同，请注意适用的基金业务类型*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/
SELECT SPLIT_PART(mn_prod_cd, '+', 1) 产品代码  
      ,mn_prod_nm 产品名称
      ,SUM(CASE
               WHEN fnd_bsns_typ_cd IN ('120', '122', '137', '139') THEN
                fnct_crrn_cnfr_amnt --确认金额（本币）
               ELSE
                0
           END) / 10000 AS '申购（万元）'
      ,SUM(CASE
               WHEN fnd_bsns_typ_cd IN ('124', '138', '142', '163') THEN
                fnct_crrn_cnfr_amnt --确认金额（本币）
               ELSE
                0
           END) / 10000 AS '赎回（万元）'
      ,SUM(CASE
               WHEN fnd_bsns_typ_cd IN ('120', '122', '137', '139') THEN
                fnct_crrn_cnfr_amnt
               WHEN fnd_bsns_typ_cd IN ('124', '138', '142', '163') THEN
                fnct_crrn_cnfr_amnt * -1 --确认金额（本币）
               ELSE
                0
           END) / 10000 AS '净申购（万元）'
  FROM DTLAB_R.v_dws_mkt_all_chnn_trd_indx
 WHERE cnfr_rslt_cd = '1' AND ---取确认成功的数据
	   prod_typ_203427 = '公募' AND	--取公募基金
       appl_dt BETWEEN TO_DATE('20230901', 'YYYYMMDD') AND TO_DATE('20230908', 'YYYYMMDD') AND --申请日期
       fnd_bsns_typ_cd IN ('120', '122', '124', '137', '138', '139', '142', '163')
--120认购 122申购 124赎回 137基金转换转入 138基金转换转出 139定期定额申购 142强制赎回 163 定时定额赎回
 GROUP BY split_part(mn_prod_cd, '+', 1)
         ,mn_prod_nm
ORDER BY  SPLIT_PART(mn_prod_cd, '+', 1);
```

## 查询说明
此查询用于从数据库中提取特定日期范围内公募产品的申购、赎回及净申购的数据。查询结果以万元为单位显示，并按产品代码排序。

## 条件说明
- `cnfr_rslt_cd = '1'`：表示只选择确认成功的交易记录。
- `prod_typ_203427 = '公募'`：表示只选择公募基金类型的交易。
- `appl_dt BETWEEN TO_DATE('20230901', 'YYYYMMDD') AND TO_DATE('20230908', 'YYYYMMDD')`：表示选择申请日期在2023年9月1日至2023年9月8日之间的交易。
- `fnd_bsns_typ_cd IN ('120', '122', '124', '137', '138', '139', '142', '163')`：表示选择特定的基金业务类型代码，包括认购、申购、赎回等。

## 业务场景
此查询适用于营销管理部门，帮助分析特定时间段内公募基金的市场表现，特别是申购和赎回的情况，以及净申购的变化趋势，为后续的市场策略提供数据支持。

## 问题说明
- 由于表的权限不同，查询结果可能因执行者的权限而异，需要注意查询结果的完整性和准确性。
- 确认金额（本币）字段`fnct_crrn_cnfr_amnt`需要确保其单位与计算结果的一致性，避免单位换算错误。

## 优化建议

- 对于频繁使用的查询，可以考虑创建视图或物化视图，减少每次查询时的计算量。
- 定期检查和更新统计信息，确保查询优化器能够选择最优的执行计划。
