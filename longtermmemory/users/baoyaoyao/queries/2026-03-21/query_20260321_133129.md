# 查询指定申请日期、指定产品、指定渠道，交易金额大于X的客户申赎明细数据

## 查询目的
查询在指定申请日期范围内，通过指定渠道购买指定产品的客户申赎明细数据，且交易金额大于或等于设定值。

## SQL查询
```sql
/* 名称：查询指定申请日期、指定产品、指定渠道，交易金额大于X的客户申赎明细数据*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/

SELECT appl_dt             申请日期
      ,cstm_srrg_key       客户号
      ,cstm_fll_nm         客户名称
      ,fnd_acct            基金账号
      ,trd_acct            交易账户
      ,fnd_bsns_typ        基金业务类型
      ,fnd_bsns_typ_cd     基金业务类型代码
      ,prov                省份
      ,cty                 城市
      ,sbbr_sl_dprt        支行网点
      ,fnct_crrn_cnfr_amnt 确认金额
      ,cnfr_shr            确认份额
  FROM DTLAB_R.v_dws_mkt_all_chnn_trd_indx   
 WHERE appl_dt BETWEEN '20230220' AND '20230303' AND --申请日期
       sll_chnn_cd_0 = '015' AND --中国邮政邮储
       prod_cd IN ('000109', '000107') AND --富国稳健增强，基金代码：000107、000109
       cnfr_rslt_cd = '1' AND --确认成功
       fnd_bsns_typ_cd IN ('139', '122', '124') AND --139:定期定额申购 122 申购 124 赎回
       orgn_crrn_cnfr_amnt >= 200000 --交易金额大于等于20万
```

## 查询说明
此查询用于从数据库中提取特定条件下的客户申赎明细数据。查询条件包括申请日期范围、销售渠道、产品代码、交易类型和交易金额等。

## 条件说明
- **申请日期**：查询的日期范围为2023年2月20日至2023年3月3日。
- **销售渠道**：指定为中国邮政邮储（代码015）。
- **产品代码**：查询的产品为富国稳健增强，基金代码分别为000107和000109。
- **交易状态**：仅查询确认成功的交易（确认结果代码为1）。
- **交易类型**：包括定期定额申购（139）、申购（122）和赎回（124）。
- **交易金额**：交易金额需大于或等于20万元。

## 业务场景
此查询适用于市场营销管理分析中的客户行为分析，特别是针对特定产品和渠道的高价值交易进行深入分析，以支持市场策略制定和客户关系管理。

## 问题说明
- **权限问题**：由于不同的用户可能具有不同的表访问权限，查询结果可能会有所不同。
- **数据准确性**：确保所有输入参数的正确性，特别是日期格式和产品代码。
