# 查询指定净值日期的全产品转融通交易市值（含利息）信息

## 查询目的
查询指定净值日期的全产品转融通交易市值（含利息）信息，以便进行投资组合分析。

## SQL查询
```sql
/* 名称：查询指定净值日期的全产品转融通交易市值（含利息）信息*/
/* 说明：由于表权限不同，可能得到的产品结果范围不同*/
/* 编写人员：蔡济烈*/
/* 联系方式：021-20363171 18001812349*/
/* 编写日期：20230908*/

select
  a.prod_cd 产品代码,
  a1.bsns_dt 净值日期,
  a.scrt_wind_cd 股票代码,
  a.scrt_chn_abbr 股票名称,
  a.trd_mkt_cd 交易市场代码,
  b.enmr_nm 交易市场,
  a.dl_qntt 交易数量,
  a1.fnct_crrn_hldn_mrkt_vl "股票市值（折人民币）",
  a1.fnct_crrn_accm_accr_intr "转融通累计利息（折人民币）"  
from
 dtlab_r.v_dwm_inv_rfnn_invs_trd_dly_accm_accr_intr_flw a1
left join dtlab_r.v_dwm_inv_rfnn_invs_trd_flw a on a.srl_nmbr=a1.srl_nmbr 
left join dtlab_r.v_para_stnd_cd b on  b.enmr_fld='trd_mkt_cd' and b.enmr_cd=a.trd_mkt_cd
where
  a1.bsns_dt = '20230907' /*净值日期*/
```

## 查询说明
此查询用于获取指定净值日期的所有产品的转融通交易市值及累计利息信息。通过连接多个视图，可以获取到产品的详细交易信息和市场信息。

## 条件说明
- `a1.bsns_dt = '20230907'`：指定查询的净值日期为2023年9月7日。可以根据需要修改此日期以查询其他日期的数据。

## 业务场景
此查询适用于投资组合管理中的资产估值和风险管理，特别是在需要了解特定日期内所有产品的转融通交易情况时。

## 问题说明
- 由于表权限的不同，查询结果中可能包含的产品范围会有所不同。
- 确保查询日期格式正确，并且数据库中有相应的数据记录。

## 优化建议
- 如果查询性能较低，可以考虑对常用字段建立索引，如`bsns_dt`、`prod_cd`等。
- 定期检查和维护数据库索引，确保其有效性。
- 对于大数据量的查询，可以考虑使用分区表来提高查询效率。
