# 查询所有存续期公募产品清单，含母子基金关系

## 查询目的
查询所有存续期公募产品的清单，并包含母子基金的关系。

## SQL查询
```sql
/* 名称：查询所有存续期公募产品清单，含母子基金关系*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/
SELECT split_part(uppr_prod_srrg_key, '+', 1) 主基金代码
      ,prod_chn_fll_nm_60001 主基金名称
      ,prod_cd 子基金代码
      ,prod_chn_abbr_intr_use_200136 子基金名称
  FROM DTLAB_R.v_dim_prod_dmns
 WHERE prod_typ_cd_203427 = '1' AND --公募
       prod_stt_cd_200282 IN ('8', '7') AND --存续期 ：8 运作开放，7 运作封闭 
       prod_lvl = '1' ---取产品层级是1，找出母子基金关系
 ORDER BY uppr_prod_srrg_key,prod_cd
```

## 查询说明
此查询用于从数据库中提取所有当前处于存续期的公募基金产品信息，包括主基金和子基金的详细信息。由于不同的用户可能具有不同的表访问权限，因此查询结果可能会有所不同。

## 条件说明
- `prod_typ_cd_203427 = '1'`：筛选出公募基金类型的产品。
- `prod_stt_cd_200282 IN ('8', '7')`：筛选出处于存续期的产品，其中状态码 '8' 表示运作开放，'7' 表示运作封闭。
- `prod_lvl = '1'`：筛选出产品层级为1的记录，以确保能够获取到母子基金的关系。

## 业务场景
此查询适用于市场营销管理分析中的产品管理模块，帮助市场分析师或产品经理了解当前市场上所有存续期的公募基金产品及其母子基金关系，以便进行更深入的市场分析和产品策略制定。

## 问题说明
- 由于表的权限限制，某些用户可能无法看到全部的产品数据。
- 查询结果的准确性依赖于数据库中数据的完整性和及时性。

## 优化建议
- 定期检查和更新数据库中的产品状态信息，确保数据的准确性和时效性。
- 对于有权限限制的用户，可以考虑通过角色管理和权限分配来适当放宽访问权限，以提高数据的可用性。
- 在查询性能上，如果数据量较大，可以考虑对常用字段建立索引，以加快查询速度。
