# 查询指定日期区间、指定产品的持有人户数每日变化趋势

## 查询目的
查询指定日期区间内，特定产品的持有人户数每日变化趋势，以便于进行市场管理与分析。

## SQL查询
```sql
/* 名称：查询指定日期区间、指定产品的持有人户数每日变化趋势*/
/* 说明：客户按ECIF客户号统计，由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/
SELECT clnd_dt 自然日期
       ,split_part(mn_prod_cd, '+', 1) 主基金代码
       ,mn_prod_nm 主基金名称
       ,COUNT(DISTINCT fnd_acct_srrg_key) 持有账户数
       ,COUNT(DISTINCT cstm_srrg_key) 持有客户数
   FROM DTLAB_R.v_dws_mkt_all_chnn_hld_indx
  WHERE clnd_dt BETWEEN '20230831' AND '20230910' AND --自然日期
        split_part(mn_prod_cd, '+', 1) = '161005' AND --主基金产品
        shr_blnc > 0 --取份额大于0
  GROUP BY clnd_dt
          ,split_part(mn_prod_cd, '+', 1)
          ,mn_prod_nm
  ORDER BY clnd_dt ASC
```

## 查询说明
此查询用于统计在指定日期区间内，特定产品的持有人户数（包括持有账户数和持有客户数）的每日变化情况。客户按ECIF客户号统计，由于表的权限不同，可能得到的产品结果范围会有所不同。

## 条件说明
- `clnd_dt BETWEEN '20230831' AND '20230910'`：指定查询的日期区间为2023年8月31日至2023年9月10日。
- `split_part(mn_prod_cd, '+', 1) = '161005'`：指定查询的主基金产品代码为161005。
- `shr_blnc > 0`：只统计份额大于0的记录。

## 业务场景
此查询适用于市场营销管理中的产品表现分析，帮助了解特定产品在市场上的持有情况及其变化趋势，为后续的市场策略调整提供数据支持。

## 问题说明
- 如果查询结果为空，可能是由于指定的日期区间或产品代码没有相应的数据，或者当前用户的表权限限制了数据的可见性。
- 确保查询的日期格式正确，并且符合数据库中存储的日期格式。

## 优化建议
- 对于频繁执行的查询，可以考虑创建索引以提高查询效率，特别是对`clnd_dt`和`mn_prod_cd`字段。
- 定期检查和更新表的统计信息，确保查询优化器能够选择最优的执行计划。
- 如果查询涉及大量数据，可以考虑使用分区表来减少扫描的数据量，提高查询性能。
