# 查询全市场公募基金组合持仓股票清单

## 查询目的
查询全市场公募基金组合产品在定期报告中的持仓股票清单，包括报告期限制，以便追查历史报告期的持股情况。季度报告中仅披露前十大持仓股票，而半年报和年报则披露所有持仓股票。

## SQL查询
```sql
/* 名称：查询全市场公募基金组合持仓股票清单*/
/* 说明：
a、查询范围为全市场公募基金组合产品，定期报告中的持仓股票清单。
b、需要设置报告期限制，这样能追查历史报告期的持股情况。
c、季度报告中只披露前十大持仓股票、半年报和年报披露所有持仓股票*/
/* 编写人员：nayuming*/
/* 需求来源：战略产品部 */
/* 版本：20220920*/
/* 编写日期：20220920*/
/* 参数：公募基金代码、报告期*/
select
  a.s_info_windcode as "基金Wind代码",
  substr (a.s_info_windcode, 1, 6) as "基金代码",
  b.F_INFO_NAME as "基金简称",
  f_prt_enddate as "报告期截止日期",
  s_info_stockwindcode as "持有股票Wind代码",
  c.S_INFO_CODE as "持仓股票代码",
  c.S_INFO_NAME as "持仓股票名称",
  f_prt_stkvalue as "持有股票市值(元)",
  f_prt_stkquantity as "持有股票数量（股）",
  f_prt_stkvaluetonav as "持有股票市值占基金净值比例(%)",
  stock_per as "占股票市值比"
from
  dtlab_r.v_s034_wfdb_chinamutualfundstockportfolio a
  inner join dtlab_r.v_s034_wfdb_chinamutualfunddescription b on a.s_info_windcode = b.f_info_windcode
  inner join dtlab_r.v_s034_wfdb_asharedescription c on a.s_info_stockwindcode = c.s_info_windcode
where
  (
    a.s_info_windcode = '161005.SZ'
    or substr (a.s_info_windcode, 1, 6) = ''
  ) -- 限制产品代码  a.s_info_windcode ='' or substr(a.s_info_windcode,1,6) ='161005'
  and a.f_prt_enddate = '20230331' -- 设置报告期截止日期
order by
  a.f_prt_stkvalue desc
```

## 查询说明
此查询用于获取指定报告期内全市场公募基金组合产品的持仓股票详细信息，包括基金的基本信息、持仓股票的信息以及持仓的具体数据。通过设置报告期，可以查看不同时间点的持仓情况。

## 条件说明
- **公募基金代码**：用于限定查询的公募基金产品，支持完整的Wind代码或简化的6位基金代码。
- **报告期**：用于限定查询的报告期截止日期，确保查询结果反映特定时间点的数据。

## 业务场景
此查询适用于投资组合分析，特别是对公募基金的投资策略和市场表现进行深入研究时，能够提供详细的持仓数据支持。

## 问题说明
- 确保输入的公募基金代码和报告期截止日期准确无误，以避免查询结果不正确。
- 季度报告中仅显示前十大持仓股票，而半年报和年报则显示所有持仓股票。
