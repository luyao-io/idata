# 根据基金代码查询一段时间的期货交易信息

## 查询目的
根据基金代码查询特定时间段内的期货交易信息，包括产品代码、产品名称、产品类型、交易日期、交易方向、买卖方向、合约名称、合约代码、合约数量和合约金额。

## SQL查询
```sql
/*名称：根据基金代码查询一段时间的期货交易信息*/
/*说明：由于表的权限不同，可能得到的产品结果范围不同，请注意适用的基金业务类型*/
/*编写人员：刘雨*/
/*联系方式：*/
/*编写日期：20241213*/
SELECT t2.prod_cd as "产品代码"
      ,t2.prod_chn_abbr_intr_use_200136 as "产品名称" 
      ,t2.prod_typ_203427 as "产品类型"
      ,bsns_dt as "交易日期"
      ,CASE
           WHEN trd_mthd_cd ILIKE '%QHJY_JG%' THEN
                    '交割'
           WHEN trd_mthd_cd ILIKE '%QHJY_KC%' THEN
            '开仓'
            WHEN trd_mthd_cd ILIKE '%QHJY_PC%' THEN
            '平仓'
       END as "交易方向"
      ,CASE
           WHEN trd_attr_cd ILIKE '%SELL%' THEN
            '空头'
           WHEN trd_attr_cd ILIKE '%buy%' THEN
            '多头'
       END as "买卖方向"
      ,scrt_chn_fll_nm as "合约名称"
      ,t.scrt_cd as "合约代码"
      ,dl_qntt as "合约数量"
      ,fnct_crrn_trnv_amnt as "合约金额"
  FROM dtlab_r.v_dwd_inv_invs_trd_flw t
  LEFT JOIN dtlab_r.v_dim_scrt_dmns t1
    ON t.scrt_srrg_key = t1.scrt_srrg_key
  LEFT JOIN dtlab_r.v_dim_prod_dmns t2
    ON t2.prod_srrg_key = t.prod_srrg_key AND
       t2.prod_lvl = '0' 
 WHERE trd_typ_cd = 'QHJY' AND
       bsns_dt BETWEEN '20241201' AND '20241212' and
       t2.prod_cd = '800035'
```

## 查询说明
此查询用于从数据库中提取特定基金代码在指定时间范围内的期货交易记录。查询结果包括产品的基本信息以及每笔交易的具体细节。

## 条件说明
- **交易日期**：查询的时间范围为2024年12月1日至2024年12月12日。
- **产品代码**：查询的产品代码为800035。

## 业务场景
此查询适用于投资组合分析中的期货交易监控，帮助基金经理或分析师了解特定基金在特定时间段内的期货交易活动，以便进行进一步的分析和决策。

## 问题说明
- **表的权限**：不同的用户可能具有不同的表访问权限，这可能影响查询结果的完整性和准确性。
- **交易类型**：查询仅限于期货交易（`trd_typ_cd = 'QHJY'`）。

## 优化建议
- **索引优化**：确保`bsns_dt`、`prod_cd`、`trd_typ_cd`等常用过滤字段上有适当的索引，以提高查询性能。
- **分区表**：如果数据量较大，可以考虑对表进行分区，特别是按交易日期进行分区，以加快查询速度。
- **定期维护**：定期检查和维护数据库索引，确保其有效性，避免因索引失效导致的性能下降。
