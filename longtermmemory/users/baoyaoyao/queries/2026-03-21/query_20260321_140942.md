# 按基金代码查询某一时点的非标产品信息

## 查询目的
按基金代码查询某一时点的非标产品信息，以帮助投资研究人员了解特定基金在指定时间点的投资组合详情。

## SQL查询
```sql
/*名称：按基金代码查询某一时点的非标产品信息*/
/*说明：由于表的权限不同，可能得到的产品结果范围不同，请注意适用的基金业务类型*/
/*编写人员：刘雨*/
/*联系方式：*/
/*编写日期：20241213*/
SELECT a10.prod_cd as "基金代码"
       ,a10.vltn_dt as "数据日期"
       ,a10.prod_chn_fll_nm_60001 as "基金名称"
       ,a20.prod_typ_203427 as "基金类型"
       ,replace(scrt_dtl_typ,'理财品种_','') as "产品类别"
       ,a10.non_stnd_scrt_chn_abbr as "产品名称"
       ,a10.non_stnd_invs_undr_srrg_key as "证券代码"
       ,COALESCE(to_number(a50.cpn_rt), a40.cpn_rt)/100 as "利率"
       ,a10.dwnp_dt as "首期日期"
       ,a10.mtrt_dt as "到期日期"
       ,a10.hldn_cst_fnct_crrn as "成本"
       ,a10.fnct_crrn_hldn_mkt_vl as "市值"
       ,a10.hldn_qntt as "数量"
       ,a10.fnct_crrn_mkt_vl_rt as "期末市值占净值比"
  FROM dtlab_r.v_dwm_inv_prod_invs_non_stnd_undr_hldn_dtls a10
  left join dtlab_r.v_dim_prod_dmns a20
    on a10.prod_srrg_key=a20.prod_srrg_key
    LEFT JOIN dtlab_r.v_dim_non_stnd_invs_undr_dmns a40
    ON a10.non_stnd_invs_undr_srrg_key = a40.non_stnd_invs_undr_srrg_key 
  LEFT JOIN (SELECT vltn_scrt_intr_cd
                   ,MAX(adjs_dt) adjs_dt
               FROM dtlab_r.v_dwd_inv_bnd_pay_int_flw a10
              WHERE adjs_dt <= '20241212' /*输入日期*/
              GROUP BY vltn_scrt_intr_cd) b1
    ON a10.non_stnd_invs_undr_srrg_key = replace(b1.vltn_scrt_intr_cd,' OTC','')
  LEFT JOIN dtlab_r.v_dwd_inv_bnd_pay_int_flw a50
    ON a50.vltn_scrt_intr_cd = b1.vltn_scrt_intr_cd AND
       b1.adjs_dt = a50.adjs_dt
  where a10.vltn_dt= '20241212' and  /*输入日期*/
        a10.prod_cd = '10B001' /*输入产品代码*/
order by a10.prod_cd
       ,a10.vltn_dt
```

## 查询说明
此查询用于从数据库中提取特定基金在指定日期的非标产品详细信息。查询结果包括基金代码、数据日期、基金名称、基金类型、产品类别、产品名称、证券代码、利率、首期日期、到期日期、成本、市值、数量和期末市值占净值比等信息。

## 条件说明
- `vltn_dt`：数据日期，需要根据实际查询需求输入具体日期（例如：'20241212'）。
- `prod_cd`：基金代码，需要根据实际查询需求输入具体的基金代码（例如：'10B001'）。

## 业务场景
此查询适用于投资组合分析中的基金投资研究，特别是对于非标准化产品的投资分析，帮助投资经理或研究员快速获取特定基金在某一时间点的非标产品配置情况。

## 问题说明
- 由于表的权限不同，查询结果可能因执行者的权限而异，需要注意适用的基金业务类型。
- 输入的日期和基金代码需确保正确无误，以避免查询不到数据或返回错误的数据。
