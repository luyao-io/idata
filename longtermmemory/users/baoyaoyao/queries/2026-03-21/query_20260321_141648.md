# 查询全市场公募基金组合持仓债券清单

## 查询目的
查询全市场公募基金组合产品在定期报告中的持仓债券清单，包括报告期限制，以便能够追查历史报告期的持股情况。季度报告中仅披露前十大持仓债券，而半年报和年报则披露所有持仓债券。

## SQL查询
```sql
/* 名称：查询全市场公募基金组合持仓债券清单*/
/* 说明：
a、查询范围为全市场公募基金组合产品，定期报告中的持仓债券清单。
b、需要设置报告期限制，这样能追查历史报告期的持股情况。
c、季度报告中只披露前十大持仓债券、半年报和年报披露所有持仓债券*/
/* 编写人员：nayuming*/
/* 需求来源：战略产品部 */
/* 版本：20220920*/
/* 编写日期：20220920*/
/* 参数：公募基金代码、报告期*/
select
  a.s_info_windcode as "基金Wind代码",
  substr (a.s_info_windcode, 1, 6) as "基金代码",
  b.f_info_name as "基金简称",
  f_prt_enddate as "报告期截止日期",
  s_info_bondwindcode as "持有债券Wind代码",
  c.s_info_name as "持仓债券简称",
  a.f_prt_bdvalue as "持有债券市值(元)",
  a.f_prt_bdquantity as "持有债券数量（张）",
  a.f_prt_bdvaluetonav as "持有债券市值占基金净值比例(%)"
from
  dtlab_r.v_s034_wfdb_chinamutualfundbondportfolio a
  inner join dtlab_r.v_s034_wfdb_chinamutualfunddescription b on a.s_info_windcode = b.f_info_windcode
  inner join dtlab_r.v_s034_wfdb_cbonddescription c on a.s_info_bondwindcode = c.s_info_windcode
where
  (
    a.s_info_windcode = '161005.SZ'
    or substr (a.s_info_windcode, 1, 6) = ''
  ) -- 限制产品代码  a.s_info_windcode ='' or substr(a.s_info_windcode,1,6) ='161005'
  and a.f_prt_enddate = '20230331' -- 设置报告期截止日期
order by
  a.f_prt_bdvalue desc
```

## 查询说明
此查询用于获取指定报告期内全市场公募基金组合产品的持仓债券详细信息，包括基金的基本信息、持仓债券的信息以及持仓的具体数值等。

## 条件说明
- **公募基金代码**：可以通过`a.s_info_windcode`或其前六位`substr(a.s_info_windcode, 1, 6)`来限制查询的基金范围。
- **报告期**：通过`a.f_prt_enddate`来设定查询的报告期截止日期，例如`20230331`表示2023年第一季度的报告。

## 业务场景
适用于投资组合分析，特别是对公募基金的投资策略和持仓变化进行深入研究，帮助投资者了解基金的资产配置情况，辅助做出投资决策。

## 问题说明
- 确保输入的公募基金代码和报告期截止日期准确无误。
- 季度报告中仅显示前十大持仓债券，而半年报和年报则显示所有持仓债券。

## 优化建议
- 对于频繁查询的报告期，可以考虑建立索引以提高查询效率。
- 定期检查数据表的更新情况，确保数据的时效性和准确性。
- 在生产环境中执行复杂查询时，建议先在测试环境中验证查询性能。
