# 查询余额宝指定日期的尾佣费用

## 查询目的
查询指定日期天时余额宝的尾佣费用，以便于营销管理分析。

## SQL查询
```sql
/* 名称：查询指定日期天时余额宝的尾佣费用*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同，请注意适用的基金业务类型*/
/* 编写人员：赵阳*/
/* 联系方式：021-20513209*/
/* 编写日期：20231110*/
select
a.clnd_dt + 1 日期
,a.sll_chnn_cd_0 销售商代码
,a.sll_chnn_abbr_0 销售商简称
,a.cstm_typ 客户类型
,a.shr_blnc 保有规模
,b.ratio 尾佣费率
,a.shr_blnc * b.ratio / 365 尾随佣金
from dtlab_r.v_dws_mkt_all_chnn_hld_indx a
left join dtlab_r.v_s094_yjta_tail_ratio b
on to_date(b.begin_date,'yyyymmdd') <= a.clnd_dt and to_date(b.end_date,'yyyymmdd') > a.clnd_dt and a.sll_chnn_cd_0 = b.distributor_code and a.prod_cd = b.fund_code and a.cstm_typ_cd = b.investor_type
/*305蚂蚁基金、926网商银行*/
where a.sll_chnn_cd_0 in ('305','926')
and a.ta_cd = 'YJTA'
/*根据需求修改日期，日期要往前移一天*/
and a.clnd_dt between '20230930' and '20231030'
```

## 查询说明
此查询用于获取指定日期范围内余额宝的尾佣费用。查询中使用了两个表`dtlab_r.v_dws_mkt_all_chnn_hld_indx`和`dtlab_r.v_s094_yjta_tail_ratio`，通过销售商代码、产品代码和客户类型进行关联，并计算每日的尾随佣金。

## 条件说明
- `a.sll_chnn_cd_0 in ('305','926')`: 指定查询的销售商为蚂蚁基金（代码305）和网商银行（代码926）。
- `a.ta_cd = 'YJTA'`: 指定查询的登记机构代码为'YJTA'，即余额宝。
- `a.clnd_dt between '20230930' and '20231030'`: 指定查询的日期范围为2023年9月30日至2023年10月30日，实际查询日期需往前移一天。

## 业务场景
此查询适用于营销管理分析中的成本控制与效益评估，特别是针对特定销售商和特定时间段内的尾佣费用分析，帮助管理层做出更精准的决策。

## 问题说明

- 日期条件需要根据实际需求进行调整，确保查询的日期范围准确无误。
