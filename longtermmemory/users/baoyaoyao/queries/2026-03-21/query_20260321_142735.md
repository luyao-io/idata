# 查询组合股票交易明细

## 查询目的
查询特定基金在指定日期范围内的股票交易明细，包括交易日期、证券代码、证券简称、成交数量、成交金额等详细信息。

## SQL查询
```sql
/* 名称：查询组合股票交易明细*/
/* 说明：1.由于表权限不同，可能得到的产品结果范围不同*/
/* 编写人员：罗宇锋*/
/* 联系方式：021-80305443 17717874502*/
/* 编写日期：20230911*/

select
a.prod_cd as 产品代码,
a.prod_lvl as 产品层级,
a.trd_dt as 交易日期,
a.scrt_wind_cd as 证券代码,
a.scrt_chn_abbr as 证券简称,
a.dl_qntt as 成交数量,
a.fnct_crrn_trnv_amnt as 成交金额,
a.fnct_crrn_trns_fee as 过户费,
a.fnct_crrn_admn_fee as 征管费,
a.fnct_crrn_stmp_tax as 印花税,
a.fnct_crrn_stck_trdn_fee as 经手费,
a.fnct_crrn_pybl_cmms as 应付佣金
from dtlab_r.v_dwm_inv_stck_invs_trd_flw a
where a.prod_cd in ('800032') --筛选对应的基金
and a.trd_dt >= date '2023-09-07'  --筛选对应的日期
```

## 查询说明
此查询用于获取特定基金（产品代码为'800032'）自2023年9月7日以来的所有股票交易记录。查询结果将包含产品的代码、层级、交易日期、证券代码、证券简称、成交数量、成交金额以及各种费用等信息。

## 条件说明
- `prod_cd`：产品代码，用于筛选特定的基金。当前设置为'800032'。
- `trd_dt`：交易日期，用于筛选从2023年9月7日开始的交易记录。

## 业务场景
此查询适用于投资组合分析中的股票交易监控，帮助分析师或基金经理了解特定基金的股票交易活动，以便进行进一步的投资决策和风险管理。

## 问题说明
- 表权限不同可能导致查询结果中包含的产品范围不同。
- 确保数据库连接和权限配置正确，以避免查询失败。

## 优化建议
- 如果查询性能不佳，可以考虑对`prod_cd`和`trd_dt`字段建立索引。
- 定期检查和更新表统计信息，以提高查询优化器的选择性估计。
- 对于频繁使用的查询，可以考虑使用物化视图来加速数据访问。
