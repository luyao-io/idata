# 获取银河基金分类的基金清单

## 查询目的
获取银河基金分类的基金清单，查询范围为银河发布最新的基金分类，全市场基金清单数据。可以按照基金代码、一级分类代码、二级分类代码、三级分类代码分别筛选。

```sql
/*获取银河基金分类的基金清单*/
/* 说明：

b、可以按照 基金代码、一级分类代码、二级分类代码、三级分类代码 分别筛选。
*/

/* 需求来源：风险管理 */

select classify_lvl1code,
       classify_lvl1name,
       classify_lvl2code,
       classify_lvl2name,
       classify_lvl3code,
       classify_lvl3name,
       s_info_windcode
  from dtlab_r.v_s081_pdata_yhfund_classify
```

## 查询说明
此查询用于从银河基金分类中提取基金清单，包括基金的一级、二级和三级分类代码及名称，以及基金代码。查询结果可以帮助用户了解不同分类下的基金分布情况。

## 条件说明
- `s_info_windcode`：基金代码，当前查询条件为空，表示查询所有基金。可以根据需要填写具体的基金代码进行筛选。

## 业务场景
此查询适用于外部信息分析领域，特别是风险管理方面，帮助分析师或投资者了解市场上的基金分类情况，以便做出更合理的投资决策。
