# 根据基金代码或股票代码（名称）查询某一时点的股票持仓信息

## 查询目的
根据基金代码或股票代码（名称）查询某一时点的股票持仓信息，以便进行投资组合分析。

## SQL查询
```sql
/*名称：根据基金代码或股票代码（名称）查询某一时点的股票持仓信息*/
/*说明：由于表的权限不同，可能得到的产品结果范围不同，请注意适用的基金业务类型*/
/*编写人员：刘雨*/
/*联系方式：*/
/*编写日期：20241213*/
with tmp as
(
select a10.scrt_srrg_key
          ,max(a20.src_syst_scrt_intr_cd) src_syst_scrt_intr_cd
 from dtlab_r.v_dim_scrt_dmns a10
 join dtlab_r.v_dwd_pub_scrt_mstr_dat_cd_rltn a20
    on a10.scrt_srrg_key=a20.scrt_srrg_key and a20.src_syst_cd IN ('FA')
where trd_crrn_cd NOT IN ('CNY','HKD') and a10.scrt_typ_cd='GP'
group by a10.scrt_srrg_key
)
SELECT a10.prod_cd as "基金代码"
       ,a10.prod_chn_fll_nm_60001 AS "基金名称"
       ,coalesce(a10.stck_scrt_wind_cd,a20.scrt_cd) AS "股票代码"
       ,a10.stck_scrt_chn_abbr AS "股票名称"
       ,a10.fnct_crrn_hldn_mkt_vl AS "市值"
       ,a10.hldn_qntt AS "数量"
       ,a10.hldn_cst_fnct_crrn AS "成本"
       ,a10.fnct_crrn_mkt_vl_rt AS "占基金净值比例"
       ,coalesce(a10.wind_lvl_1_inds_nm,'')||coalesce('--'||a10.wind_lvl_2_inds_nm,'')||coalesce('--'||a10.wind_lvl_3_inds_nm,'')||coalesce('--'||a10.wind_lvl_4_inds_nm,'')   AS "wind行业名称"
       ,coalesce(a10.sw_lvl_1_inds_nm,'')||coalesce('--'||a10.sw_lvl_2_inds_nm,'')||coalesce('--'||a10.sw_lvl_3_inds_nm,'') AS "申万行业名称"
       ,coalesce(a10.csrc_lvl_1_inds_nm,'')||coalesce('--'||a10.csrc_lvl_2_inds_nm,'')||coalesce('--'||a10.csrc_lvl_3_inds_nm,'') AS "证监会行业名称"
    ,coalesce(a10.wind_lvl_1_inds_nm,'')||coalesce('--'||a10.wind_lvl_2_inds_nm,'')||coalesce('--'||a10.wind_lvl_3_inds_nm,'')||coalesce('--'||a10.wind_lvl_4_inds_nm,'')   AS "gics行业名称"
       ,a10.frst_buy_dt AS "首次买入日期"
       ,a20.isin_cd AS "ISIN代码"
      ,a20.ipo_mkt as "交易市场"
    ,coalesce(a10.stck_scrt_wind_cd,a30.src_syst_scrt_intr_cd) as "证券代码_风控"
       ,a10.rcnt_buy_dt AS "最近买入日期"
       ,coalesce(a10.sw_lvl_1_inds_nm,'') as "申万一级行业"
   FROM dtlab_r.v_dwm_inv_prod_invs_stck_hldn_dtls a10
   LEFT JOIN dtlab_r.v_dim_scrt_dmns a20
      ON a10.stck_scrt_srrg_key=a20.scrt_srrg_key
LEFT JOIN tmp a30
  on a10.stck_scrt_srrg_key=a30.scrt_srrg_key
    where a10.vltn_dt= '20241212' and /*输入日期*/
              a10.prod_cd = '000029' /*输入产品代码*/
```

## 查询说明
此查询用于获取特定基金在指定日期的股票持仓详情。查询结果包括基金代码、基金名称、股票代码、股票名称、市值、数量、成本、占基金净值比例、行业分类信息、首次买入日期、ISIN代码、交易市场、证券代码（风控）、最近买入日期和申万一级行业等信息。

## 条件说明
- `vltn_dt`: 指定的估值日期，例如 '20241212'。
- `prod_cd`: 基金代码，例如 '000029'。

## 业务场景
此查询适用于投资组合分析，帮助基金经理或分析师了解特定基金在某一时间点的股票持仓情况，以便进行进一步的投资决策和风险管理。

## 问题说明
- 确保输入的日期和基金代码正确无误。
- 注意表的权限设置，确保查询能够访问所需的数据。

## 优化建议
- 对于频繁使用的查询，可以考虑创建索引以提高查询性能。
- 定期检查和更新数据表，确保数据的准确性和完整性。
- 如果查询结果集较大，可以考虑分页查询或使用数据分片技术。
