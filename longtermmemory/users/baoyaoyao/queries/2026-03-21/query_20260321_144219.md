# 中信行业分级字典查询

## 查询目的
查询中信行业分级中的二级、三级和四级行业的代码及名称，特别关注代码以'b1'开头且在使用状态的行业。

## SQL查询
```sql
select p1.industriescode as swcode1,
       p1.industriesname as swname1,
       p2.industriescode as swcode2,
       p2.industriesname as swname2,
       p3.industriescode as swcode3,
       p3.industriesname as swname3
from  dtlab_r.v_s034_wfdb_ashareindustriescode P1 
inner join dtlab_r.v_s034_wfdb_ashareindustriescode P2 on  substr(p1.industriescode,1,4)=substr(p2.industriescode,1,4) and p2.industriescode like 'b1%' and p2.levelnum =3
inner join dtlab_r.v_s034_wfdb_ashareindustriescode P3 on  substr(p2.industriescode,1,6)=substr(p3.industriescode,1,6) and p3.industriescode like 'b1%' and p3.levelnum =4
where p1.levelnum =2
and p1.industriescode like 'b1%'
and p1.used = 1
order by p3.industriescode
```

## 查询说明
此查询从`dtlab_r.v_s034_wfdb_ashareindustriescode`视图中提取了中信行业分级的二级、三级和四级行业的相关信息。通过自连接的方式，确保了不同级别的行业信息能够正确关联，并且只选择了处于使用状态（`used = 1`）的行业记录。

## 条件说明
- `p1.levelnum = 2`: 筛选二级行业。
- `p1.industriescode like 'b1%'`: 行业代码以'b1'开头。
- `p1.used = 1`: 行业处于使用状态。
- `p2.levelnum = 3`: 筛选三级行业。
- `p3.levelnum = 4`: 筛选四级行业。
- `order by p3.industriescode`: 按四级行业代码排序。

## 业务场景
此查询适用于需要分析或展示中信行业分级详细信息的业务场景，特别是对于特定行业代码前缀的深入研究。

## 问题说明

- 确保数据库连接正常，视图`dtlab_r.v_s034_wfdb_ashareindustriescode`存在且可访问。
