# 查询指定自然日期的全产品各销售渠道的产品保有份额与保有金额

## 查询目的
查询指定自然日期的全产品各销售渠道的产品保有份额与保有金额，以便于进行市场管理分析。

## SQL查询
```sql
/* 名称：查询指定自然日期的全产品各销售渠道的产品保有份额与保有金额*/
/* 说明：由于表权限不同，可能得到的产品结果范围不同*/
/* 编写人员：陈东斌*/
/* 联系方式：021-20361724 13818757251*/
/* 编写日期：20230908*/
select
  a.prod_cd 产品代码,
  a.prod_nm 产品名称,
  a.sll_chnn_cd_0 销售渠道代码,
  max(a.sll_chnn_abbr_0) 销售渠道名称, --如果需要取得最新的销售渠道名称，请使用"销售渠道代理键"关联"销售渠道维度表"
  sum(a.shr_blnc) 保有份额,
  sum(a.amnt_blnc_1) 保有金额
from
  dtlab_r.v_dws_mkt_all_chnn_hld_indx a
where
  a.clnd_dt = '20230907' --自然日期
group by
  a.prod_cd,
  a.prod_nm,
  a.sll_chnn_cd_0
```

## 查询说明
此查询用于获取指定自然日期下所有产品的销售渠道、保有份额及保有金额。由于不同的用户可能具有不同的表访问权限，因此查询结果可能会有所不同。

## 条件说明
- `a.clnd_dt = '20230907'`：指定查询的自然日期为2023年9月7日。此参数可以根据实际需求调整。

## 业务场景
此查询适用于市场营销管理中的产品销售分析，帮助管理层了解不同销售渠道在特定时间点上的产品保有情况，从而做出更有效的市场策略调整。

- 表权限的不同可能导致查询结果的差异，确保执行查询的用户具有足够的权限以获得完整数据。
