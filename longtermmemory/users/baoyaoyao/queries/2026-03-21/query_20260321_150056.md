# 查询指定自然日期、指定产品的前十大持有人持有明细

## 查询目的
查询指定自然日期、指定产品的前十大持有人持有明细，以便于营销管理分析。

## SQL查询
```sql
/* 名称：查询指定自然日期、指定产品的前十大持有人持有明细*/
/* 说明：按ECIF客户号统计单一持有人，由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/
WITH tmp_v_dws_mkt_all_chnn_hld_indx AS
 (SELECT split_part(mn_prod_cd, '+', 1) mn_prod_cd
        ,mn_prod_nm
        ,cstm_srrg_key
        ,cstm_typ
        ,cstm_fll_nm
        ,SUM(amnt_blnc_7) amnt_blnc_7
    FROM DTLAB_R.v_dws_mkt_all_chnn_hld_indx
   WHERE clnd_dt = '20230831' AND --自然日期
         split_part(mn_prod_cd, '+', 1) = '161005' --主基金产品
   GROUP BY split_part(mn_prod_cd, '+', 1)
           ,mn_prod_nm
           ,cstm_srrg_key
           ,cstm_typ
           ,cstm_fll_nm),
tmp_v_dws_mkt_all_chnn_hld_indx_01 AS
 (SELECT mn_prod_cd
        ,mn_prod_nm
        ,cstm_srrg_key
        ,cstm_typ
        ,cstm_fll_nm
        ,amnt_blnc_7
        ,RANK() OVER(PARTITION BY mn_prod_cd ORDER BY amnt_blnc_7 DESC) ranks --考虑并列，空出并列所占名次
    FROM tmp_v_dws_mkt_all_chnn_hld_indx)
SELECT a1.mn_prod_cd    主基金代码
      ,a1.mn_prod_nm    主基金名称
      ,a1.ranks         名次
      ,a1.cstm_srrg_key 客户编号
      ,a1.cstm_typ      客户类型
      ,a1.cstm_fll_nm   客户名称
      ,a1.amnt_blnc_7   持有金额
      ,a1.amnt_blnc_7/NULLIFZERO(a2.tt_amnt) 持有占比
  FROM tmp_v_dws_mkt_all_chnn_hld_indx_01 a1
  LEFT JOIN (SELECT mn_prod_cd,SUM(amnt_blnc_7) tt_amnt FROM tmp_v_dws_mkt_all_chnn_hld_indx GROUP BY mn_prod_cd ) a2   ---产品总规模
  ON a1.mn_prod_cd = a2.mn_prod_cd
 WHERE a1.ranks <= 10 --取前十大
 ORDER BY a1.ranks ASC
```

## 查询说明
此查询用于获取指定自然日期和指定产品的前十大持有人的详细持有信息。通过`clnd_dt`参数指定查询的自然日期，通过`mn_prod_cd`参数指定查询的产品代码。查询结果包括持有人的客户编号、客户类型、客户名称、持有金额及持有占比等信息。

## 条件说明
- `clnd_dt`: 指定的自然日期，例如 '20230831'。
- `mn_prod_cd`: 指定的产品代码，例如 '161005'。

## 业务场景
此查询适用于营销管理分析中的客户持有情况分析，帮助了解特定产品在特定时间点的主要持有人及其持有情况，为后续的营销策略提供数据支持。

## 问题说明
- 如果表的权限不同，可能会导致查询结果中包含的产品范围有所不同。
- 使用`RANK()`函数时，如果存在并列的情况，会空出并列所占的名次。

## 优化建议
- 确保`clnd_dt`和`mn_prod_cd`参数的准确性，以避免不必要的数据处理。
- 对于大数据量的查询，可以考虑使用分区表或索引优化查询性能。
- 定期检查和更新表的统计信息，以提高查询效率。
