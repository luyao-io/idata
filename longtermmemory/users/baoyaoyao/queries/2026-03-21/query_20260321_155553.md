# 中债登估值查询取数

## 查询目的
中债估值对于存在行权的债券提供行权收益率和到期收益率两条计算结果。对于无行权债券，行权收益率和到期收益率相同。此查询旨在替换中债登估值收益率函数库表取数脚本，分别获取债券的行权收益率和到期收益率数据。

## SQL查询
### 获取债券行权收益率数据
```sql
/*按照待偿期限正向从小到大排序，获取到债券行权收益率数据*/
select
  t.s_info_windcode,
  t.trade_dt,
  t.b_anal_matu_cnbd,
  t.b_anal_dirty_cnbd,
  t.b_anal_net_cnbd,
  t.b_anal_accrint_cnbd,
  t.b_anal_yield_cnbd,
  t.b_anal_modidura_cnbd
from
  (
    select
      p.*,
      row_number() over (
        partition by
          p.s_info_windcode,
          p.trade_dt
        order by
          p.b_anal_matu_cnbd
      ) as row_num
    from
      dtlab_r.v_s034_wfdb_cbondanalysiscnbd p
  ) t
where
  row_num = 1;
```

### 获取债券到期收益率数据
```sql
/*按照待偿期限正向从大到小排序，获取到债券到期收益率数据*/
select
  t.s_info_windcode,
  t.trade_dt,
  t.b_anal_matu_cnbd,
  t.b_anal_dirty_cnbd,
  t.b_anal_net_cnbd,
  t.b_anal_accrint_cnbd,
  t.b_anal_yield_cnbd,
  t.b_anal_modidura_cnbd
from
  (
    select
      p.*,
      row_number() over (
        partition by
          p.s_info_windcode,
          p.trade_dt
        order by
          p.b_anal_matu_cnbd desc
      ) as row_num
    from
      dtlab_r.v_s034_wfdb_cbondanalysiscnbd p
  ) t
where
  row_num = 1;
```

## 查询说明
- `s_info_windcode`: 债券代码
- `trade_dt`: 交易日期
- `b_anal_matu_cnbd`: 待偿期限
- `b_anal_dirty_cnbd`: 脏价
- `b_anal_net_cnbd`: 净价
- `b_anal_accrint_cnbd`: 应计利息
- `b_anal_yield_cnbd`: 收益率
- `b_anal_modidura_cnbd`: 修正久期

## 条件说明
- 使用 `row_number()` 窗口函数对每个债券代码和交易日期组合下的记录按待偿期限进行排序，并选择每组的第一条记录。
- 第一个查询按待偿期限升序排列，用于获取行权收益率。
- 第二个查询按待偿期限降序排列，用于获取到期收益率。

## 业务场景
在投资组合分析中，需要准确获取债券的行权收益率和到期收益率，以便进行更精确的投资决策和风险管理。

## 问题说明
- 如果某些债券没有行权，则其行权收益率和到期收益率将相同。
- 需要确保数据库中的数据是最新的，以避免因数据陈旧导致的分析偏差。

## 优化建议
- 定期检查和更新数据库中的债券数据，确保数据的时效性和准确性。
- 可以考虑增加索引以提高查询性能，特别是在 `s_info_windcode` 和 `trade_dt` 字段上。
- 对于频繁使用的查询，可以考虑创建视图或物化视图来加速查询响应时间。
