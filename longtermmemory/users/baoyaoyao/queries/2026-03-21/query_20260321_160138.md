# 申万2021行业分级字典查询

## 查询目的
查询申万2021行业分级中的二级、三级和四级行业的代码及名称，特别关注代码以'76'开头且在使用状态的行业。

## SQL查询
```sql
select p1.industriescode as swcode1,
       p1.industriesname as swname1,
       p2.industriescode as swcode2,
       p2.industriesname as swname2,
       p3.industriescode as swcode3,
       p3.industriesname as swname3
from  dtlab_r.v_s034_wfdb_ashareindustriescode P1 
inner join dtlab_r.v_s034_wfdb_ashareindustriescode P2 on  substr(p1.industriescode,1,4)=substr(p2.industriescode,1,4) and p2.industriescode like '76%' and p2.levelnum =3
inner join dtlab_r.v_s034_wfdb_ashareindustriescode P3 on  substr(p2.industriescode,1,6)=substr(p3.industriescode,1,6) and p3.industriescode like '76%' and p3.levelnum =4
where p1.levelnum =2
and p1.industriescode like '76%'
and p1.used = 1
order by p3.industriescode
```

## 查询说明
此查询从`dtlab_r.v_s034_wfdb_ashareindustriescode`视图中提取了三个级别的行业信息。通过自连接的方式，确保了不同级别之间的关联性，并且只选择了特定条件下的记录。

## 条件说明
- `p1.levelnum = 2`：选择二级行业。
- `p1.industriescode like '76%'`：选择行业代码以'76'开头的记录。
- `p1.used = 1`：选择正在使用的行业记录。
- `p2.levelnum = 3` 和 `p3.levelnum = 4`：分别选择三级和四级行业。
- `p2.industriescode like '76%'` 和 `p3.industriescode like '76%'`：确保三级和四级行业也以'76'开头。
- `substr(p1.industriescode,1,4)=substr(p2.industriescode,1,4)` 和 `substr(p2.industriescode,1,6)=substr(p3.industriescode,1,6)`：确保不同级别的行业代码之间有正确的层级关系。

## 业务场景
此查询适用于投资组合分析中的行业分类研究，帮助分析师了解特定行业（如代码以'76'开头的行业）的详细分级情况，从而为投资决策提供数据支持。

## 问题说明
- 确保数据库中`dtlab_r.v_s034_wfdb_ashareindustriescode`视图的数据是最新的，以避免因数据陈旧导致的分析偏差。
- 需要检查`used`字段的定义，确认其确实表示行业是否在使用状态。

## 优化建议
- 考虑在`industriescode`和`levelnum`字段上建立索引，以提高查询性能。
- 定期更新行业数据，确保分析结果的准确性。
- 如果查询结果集较大，可以考虑分页或限制返回的记录数，以减少内存消耗和提高响应速度。
