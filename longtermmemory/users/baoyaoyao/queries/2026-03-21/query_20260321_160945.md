# 查询X产品X渠道历史以来客户盈亏情况

## 查询目的
查询X产品X渠道自产品成立以来的历史客户盈亏情况，以评估特定渠道和产品的市场表现及客户收益状况。

## SQL查询
```sql
/* 名称：查询X产品X渠道历史以来客户盈亏情况，仅支持查产品成立以来场景*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：赵阳*/
/* 联系方式：021-20513209*/
/* 编写日期：20250918*/

with tmp_base as(
select/*+ INDEX(t cstm_srrg_key) */
a.cstm_srrg_key,
sum(a.tdy_prft_lss_2) tdy_prft_lss_2,
sum(a.tdy_prft_lss_2) / sum(a.tdy_ttl_infl_amnt) syl
from dtlab_r.v_dwm_mkt_ta_non_crrn_dly_prft_and_lss a
where a.sll_chnn_cd_0 = '005'   /*限制渠道*/
and a.prod_cd IN ('000941','015690','000940')   /*限制产品*/
and a.clnd_dt <= '20250917'     /*限制截至日期*/
and a.ownd_bsns_ln IN ('零售')
group by a.cstm_srrg_key
)

select/*+ PARALLEL(a, 8) */ 
count(a.cstm_srrg_key) 客户数,
count(case when a.tdy_prft_lss_2 > 0 then cstm_srrg_key else null end) 盈利客户数,
count(case when a.tdy_prft_lss_2 > 0 then cstm_srrg_key else null end) / count(a.cstm_srrg_key) 盈利客户占比,
sum(a.tdy_prft_lss_2) 总盈亏,
avg(a.tdy_prft_lss_2) 平均盈亏,
avg(a.syl) 平均收益率
from tmp_base a
```

## 查询说明
此查询用于分析特定产品（'000941', '015690', '000940'）在特定渠道（'005'）下的客户盈亏情况。查询结果包括客户总数、盈利客户数、盈利客户占比、总盈亏、平均盈亏以及平均收益率。

## 条件说明
- 渠道代码 (`sll_chnn_cd_0`) 限定为 '005'。
- 产品代码 (`prod_cd`) 限定为 '000941', '015690', '000940'。
- 日期 (`clnd_dt`) 限定为产品成立以来至2025年9月17日。
- 业务线 (`ownd_bsns_ln`) 限定为 '零售'。

## 业务场景
此查询适用于市场营销管理分析，特别是针对特定产品和渠道的客户盈亏分析，帮助管理层了解产品在市场上的表现和客户的收益情况，从而做出更有效的市场策略调整。

## 问题说明
- 由于表的权限不同，不同的执行者可能会得到不同的产品结果范围。
- 查询中使用了索引提示 `INDEX(t cstm_srrg_key)` 和并行执行提示 `PARALLEL(a, 8)` 以提高查询性能。
