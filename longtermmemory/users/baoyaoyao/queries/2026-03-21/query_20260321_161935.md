# GICS行业数据查询脚本(港股)

## 查询目的
查询港股市场中各股票对应的GICS行业分类信息，包括行业代码、行业别名及行业名称等详细信息。

## SQL查询
```sql
--GICS行业港股对应
select 'GICS' as inds_clas,
       A.S_INFO_WINDCODE,
       lpad(substr(A.S_INFO_WINDCODE, 0, instr(A.S_INFO_WINDCODE, '.') ), 5, '0') as STOCK_CODE,
       B1.Industriesalias as INDUSTRIESALIAS1,
       B1.INDUSTRIESNAME as INDUSTRIESNAME1,
       B2.Industriesalias as INDUSTRIESALIAS2,
       B2.INDUSTRIESNAME as INDUSTRIESNAME2,
       B3.Industriesalias as INDUSTRIESALIAS3,
       B3.INDUSTRIESNAME as INDUSTRIESNAME3,
       B4.Industriesalias as INDUSTRIESALIAS4,
       B4.INDUSTRIESNAME as INDUSTRIESNAME4
  from dtlab_r.v_s081_pdata_hksharegicsindustriesclass A
  left join dtlab_r.v_s081_pdata_ashareindustriescode B4
    on substr(A.GICS_IND_CODE, 1, 10) = substr(b4.INDUSTRIESCODE, 1, 10)
   and b4.LEVELNUM = 5
   and b4.INDUSTRIESCODE like 'CHG%'
  left join dtlab_r.v_s081_pdata_ashareindustriescode B3
    on substr(A.GICS_IND_CODE, 1, 8) = substr(b3.INDUSTRIESCODE, 1, 8)
   and b3.LEVELNUM = 4
   and b3.INDUSTRIESCODE like 'CHG%'
  left join dtlab_r.v_s081_pdata_ashareindustriescode B2
    on substr(A.GICS_IND_CODE, 1, 6) = substr(b2.INDUSTRIESCODE, 1, 6)
   and b2.LEVELNUM = 3
   and b2.INDUSTRIESCODE like 'CHG%'
  left join dtlab_r.v_s081_pdata_ashareindustriescode B1
    on substr(A.GICS_IND_CODE, 1, 4) = substr(b1.INDUSTRIESCODE, 1, 4)
   and b1.LEVELNUM = 2
   and b1.INDUSTRIESCODE like 'CHG%'
 where A.CUR_SIGN = 1
   and A.GICS_IND_CODE like 'CHG%'
```

## 查询说明
此查询从`dtlab_r.v_s081_pdata_hksharegicsindustriesclass`表中获取港股的GICS行业分类信息，并通过多个左连接（`LEFT JOIN`）与`dtlab_r.v_s081_pdata_ashareindustriescode`表中的不同层级行业代码进行匹配，以获取更详细的行业分类信息。最终结果包括股票代码、各层级的行业别名和行业名称。

## 条件说明
- `A.CUR_SIGN = 1`: 表示当前有效的行业分类。
- `A.GICS_IND_CODE like 'CHG%'`: 表示行业代码以"CHG"开头，用于筛选港股市场的行业分类。
- `B1.LEVELNUM = 2`, `B2.LEVELNUM = 3`, `B3.LEVELNUM = 4`, `B4.LEVELNUM = 5`: 分别表示行业分类的不同层级，从二级到五级。

## 业务场景
此查询适用于投资组合分析中的行业分布研究，帮助投资者了解其投资组合在不同GICS行业中的配置情况，从而做出更加合理的投资决策。

## 问题说明
- 确保所有涉及的表和字段在数据库中存在且可访问。
- 检查`GICS_IND_CODE`和`INDUSTRIESCODE`字段的格式是否一致，避免因格式不匹配导致的数据错误。

## 优化建议
- 对于频繁执行的查询，可以考虑创建索引，特别是对`GICS_IND_CODE`和`INDUSTRIESCODE`字段，以提高查询性能。
- 定期检查和更新数据，确保行业分类信息的准确性和时效性。
- 如果查询结果集较大，可以考虑分页或限制返回的记录数，以减少内存使用和提高响应速度。
