# 查询指定申请日期、指定产品、指定渠道的客户地区申赎汇总数据

## 查询目的
查询指定申请日期、指定产品、指定渠道的客户地区申赎汇总数据，以便进行营销管理分析。

## SQL查询
```sql
/* 名称：查询指定申请日期、指定产品、指定渠道的客户地区申赎汇总数据*/
/* 说明：由于表的权限不同，可能得到的产品结果范围不同*/
/* 编写人员：何东美*/
/* 联系方式：021-80305441*/
/* 编写日期：20230908*/

SELECT appl_dt             申请日期
      ,fnd_bsns_typ        基金业务类型
      ,fnd_bsns_typ_cd     基金业务类型代码
      ,prov                省份
      ,cty                 城市
      ,sum(fnct_crrn_cnfr_amnt) 确认金额
      ,sum(cnfr_shr)       确认份额
  FROM DTLAB_R.v_dws_mkt_all_chnn_trd_indx   
 WHERE appl_dt BETWEEN '20230220' AND '20230303' --申请日期
   AND sll_chnn_cd_0 = '015' --中国邮政邮储
   AND prod_cd IN ('000109', '000107') --富国稳健增强，基金代码：000107、000109
   AND cnfr_rslt_cd = '1' --确认成功
   AND fnd_bsns_typ_cd IN ('139', '122', '124') --139:定期定额申购 122 申购 124 赎回
 GROUP BY 1,2,3,4,5
```

## 查询说明
此查询用于从`DTLAB_R.v_dws_mkt_all_chnn_trd_indx`视图中提取特定条件下的客户地区申赎汇总数据。查询结果包括申请日期、基金业务类型及其代码、省份、城市、确认金额和确认份额。

## 条件说明
- **申请日期**：查询的日期范围为2023年2月20日至2023年3月3日。
- **销售渠道**：仅限中国邮政邮储（代码015）。
- **产品代码**：限定为富国稳健增强基金，代码为000107和000109。
- **确认状态**：仅包含确认成功的记录（确认结果代码为1）。
- **基金业务类型**：包括定期定额申购（139）、申购（122）和赎回（124）。

## 业务场景
此查询适用于营销管理分析，帮助了解特定时间段内通过特定渠道销售的特定产品的地区分布情况，以及客户的申购和赎回行为。

## 问题说明
- 由于表的权限不同，实际查询结果可能与预期有所差异。
- 需要确保查询的日期范围、产品代码和销售渠道代码准确无误。
