# 查询证券级指标表中的指标对应值

## 查询目的
查询数仓中证券级指标表中的特定指标值，以便进行投资组合分析。

## SQL查询
```sql
/* 名称：查询数仓证券级指标表中的指标对应值*/
/* 说明：1.由于表权限不同，可能得到的产品结果范围不同*/

/*如果不确定有哪些指标，可以先执行以下这一段SQL*/
--select distinct indx_id,indx_nm from dtlab_r.v_dws_inv_prod_indx_n2 a    --去掉注释后执行

select
a.prod_cd as 产品代码,
a.prod_lvl as 产品层级,
b.prod_chn_fll_nm_60001 as 产品全称,
a.prod_wind_cd as 产品wind代码,     --产品对应的wind代码，可能为空
a.dt as 数据日期,
a.scrt_wind_cd as 证券wind代码,
c.scrt_chn_abbr as 证券简称,
c.scrt_typ as 证券类型,
c.scrt_dtl_typ as 证券明细类型,
a.indx_id as 指标ID,
a.indx_nm as 指标名称,
a.indx_vl as 指标值
from dtlab_r.v_dws_inv_prod_indx_n2 a   --产品指标表N1
inner join dtlab_r.v_dim_prod_dmns b    --产品维度表
on a.prod_srrg_key = b.prod_srrg_key
left join dtlab_r.v_dim_scrt_dmns c
on a.scrt_srrg_key = c.scrt_srrg_key    --证券主代码如果为空时，会返回"N00000"

where 1=1
and a.indx_id in ('drvi_scrt_vl_to_netasset_td_00')  --可以填入需要查询的指标
and b.prod_lvl in ('0')  --产品层级，码值对应关系():{0:母基金,1:子基金}
--and b.prod_typ_203427 in ('养老金')  --产品类型筛选，产品名称：'养老金','养老保障','一对多','职业年金','基本养老','一对一','企业年金','公募','社保'
--and a.prod_cd in ('10CA01')    --组合筛选，可填入组合代码
```

## 查询说明
此查询用于从数据仓库中提取特定证券级别的指标值。通过指定指标ID、产品层级等条件，可以精确获取所需的数据。此外，提供了查询所有可用指标的SQL语句，以帮助用户了解可选的指标范围。

## 条件说明
- `a.indx_id in ('drvi_scrt_vl_to_netasset_td_00')`：指定要查询的指标ID，可以根据实际需求修改或扩展。
- `b.prod_lvl in ('0')`：指定产品层级，0表示母基金，1表示子基金。
- `b.prod_typ_203427 in ('养老金')`：可选条件，用于筛选特定类型的产品，如养老金。
- `a.prod_cd in ('10CA01')`：可选条件，用于筛选特定的产品代码。

## 业务场景
此查询适用于投资组合分析，特别是需要详细了解特定证券在不同产品中的表现时。通过这些数据，分析师可以评估投资策略的有效性，调整投资组合，以及进行风险管理和绩效评估。

## 问题说明

- 确保有访问相关表的权限，否则可能无法获取完整的结果。
