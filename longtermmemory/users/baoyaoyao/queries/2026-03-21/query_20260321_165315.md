# A股和港股的流通股本及总股本取数

## 查询目的
获取A股和港股的最新流通股本及总股本数据，以便于投资组合分析。

## SQL查询
```sql
select s_info_windcode, change_dt,
       FLOAT_A_SHR, -- 流通A股(万股)
       S_SHARE_TOTALA  -- A股合计总股本(万股)
from (
    select *,
           row_number() over (partition by s_info_windcode order by change_dt desc) as row_num
    from dtlab_r.v_s034_wfdb_asharecapitalization
) p
where p.row_num = 1
union all
select hk.s_info_windcode, CHANGE_DATE,
       HK_OUTSTD_SHR, -- 香港流通股(万股)
       ISSUED_SHARES  -- 已发行股本(万股)
from (
    select *,
           row_number() over (partition by S_INFO_COMPCODE order by CHANGE_DATE desc) as row_num
    from dtlab_r.v_s034_wfdb_hkequitystruc
) p
inner join dtlab_r.v_s081_pdata_hksharedescription hk
on hk.S_INFO_COMPCODE = p.S_INFO_COMPCODE and SECURITYTYPE = 'ORD'
where p.row_num = 1;
```

## 查询说明
此查询从两个不同的视图中提取A股和港股的最新流通股本及总股本数据。对于A股，查询从`dtlab_r.v_s034_wfdb_asharecapitalization`视图中提取最新的流通A股和A股合计总股本；对于港股，查询从`dtlab_r.v_s034_wfdb_hkequitystruc`视图中提取最新的香港流通股和已发行股本，并通过`dtlab_r.v_s081_pdata_hksharedescription`视图过滤出普通股（ORD）的数据。

## 条件说明
- `row_number() over (partition by s_info_windcode order by change_dt desc) as row_num`：为每个股票代码（s_info_windcode）按日期（change_dt）降序排列并分配行号，确保获取最新的记录。
- `p.row_num = 1`：仅选择每组中的最新记录。
- `SECURITYTYPE = 'ORD'`：过滤出普通股类型的数据。

## 业务场景
此查询适用于投资组合管理，特别是需要定期更新A股和港股市场中各股票的流通股本和总股本信息的场景。这些数据对于评估股票的流动性、市值以及进行财务分析至关重要。

## 问题说明
- 确保数据库视图`dtlab_r.v_s034_wfdb_asharecapitalization`、`dtlab_r.v_s034_wfdb_hkequitystruc`和`dtlab_r.v_s081_pdata_hksharedescription`是最新的，并且包含所有必要的字段。
- 检查数据的一致性和完整性，特别是在合并A股和港股数据时。

## 优化建议
- 考虑在视图上创建索引，特别是对`s_info_windcode`、`change_dt`、`S_INFO_COMPCODE`和`CHANGE_DATE`字段，以提高查询性能。
- 定期检查和维护数据库统计信息，确保查询优化器能够做出最佳的执行计划。
- 如果查询性能仍然不理想，可以考虑将常用的数据缓存到临时表或物化视图中，减少重复计算。
