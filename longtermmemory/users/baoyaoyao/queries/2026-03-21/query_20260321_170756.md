# 中证指数PE数据查询demo

## 查询目的
查询中证指数的滚动市盈率（PE）及其近5年的分位数，包括历史样本和最新样本的数据，以便进行投资组合分析。

## SQL查询
```sql
select t.trade_dt as 交易日期,
       t.s_info_windcode as 指数Wind代码,
       b.s_info_compname as 指数全称,
       b.s_info_name as 指数简称,
       t.csi_his_rollpe as 指数滚动市盈率_历史样本_及时更新_计算用股本加权_剔亏,
       t.csi_his_rollpe_percentile_fy as 指数近5年滚动市盈率分位数_历史样本_及时更新_计算用股本加权_剔亏,
       t.csi_his_rollpe_loss as 指数滚动市盈率_历史样本_及时更新_计算用股本加权_不剔亏,
       t.csi_his_rollpe_percentile_fy_loss as 指数近5年滚动市盈率分位数_历史样本_及时更新_计算用股本加权_不剔亏,
       t.csi_cur_rollpe as 指数滚动市盈率_最新样本_及时更新_计算用股本加权_剔亏,
       t.csi_cur_rollpe_percentile_fy as 指数近5年滚动市盈率分位数_最新样本_及时更新_计算用股本加权_剔亏,
       t.csi_cur_rollpe_loss as 指数滚动市盈率_最新样本_及时更新_计算用股本加权_不剔亏,
       t.csi_cur_rollpe_percentile_fy_loss as 指数近5年滚动市盈率分位数_最新样本_及时更新_计算用股本加权_不剔亏
from (select *,
             row_number() over (partition by s_info_windcode order by trade_dt desc) as order_num
      from dtlab_r.v_s081_pdata_aindexcsirollpe_b22) t
inner join dtlab_r.v_s081_pdata_aindexdescription_b13 b on t.s_info_windcode = b.s_info_windcode
where t.s_info_windcode in ('931866.CSI', '950357.CSI')
  and t.order_num <= 5  -- 最近5个有效交易日
```

## 查询说明
此查询从两个视图 `dtlab_r.v_s081_pdata_aindexcsirollpe_b22` 和 `dtlab_r.v_s081_pdata_aindexdescription_b13` 中获取数据。主要字段包括交易日期、指数Wind代码、指数全称、指数简称以及各种滚动市盈率指标。通过使用窗口函数 `row_number()` 对每个指数按交易日期降序排序，并限制结果为最近5个交易日的数据。

## 条件说明
- `t.s_info_windcode in ('931866.CSI', '950357.CSI')`: 限定查询的指数Wind代码为 '931866.CSI' 和 '950357.CSI'。
- `t.order_num <= 5`: 仅选择每个指数的最近5个交易日的数据。

## 业务场景
此查询适用于投资组合分析中的市场估值分析，特别是关注中证指数的滚动市盈率变化情况，帮助投资者了解市场的估值水平及历史分位数，辅助做出投资决策。

## 问题说明
- 确保 `s_info_windcode` 字段在两个表中的一致性，以避免连接错误。
- 注意 `trade_dt` 字段的格式和时区设置，确保时间数据的准确性。

## 优化建议
- 如果查询性能较低，可以考虑对 `s_info_windcode` 和 `trade_dt` 字段建立索引。
- 定期检查和维护数据库统计信息，以提高查询优化器的选择性估计。
- 考虑使用物化视图或缓存机制来存储频繁查询的结果，减少重复计算。
