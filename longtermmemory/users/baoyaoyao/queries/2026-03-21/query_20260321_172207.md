# 根据基金代码查询某一时点的持仓养老金信息

## 查询目的
根据基金代码查询某一时点的持仓养老金信息，以便进行投资组合分析。

## SQL查询
```sql
/*名称：根据基金代码查询某一时点的持仓养老金信息*/
/*说明：由于表的权限不同，可能得到的产品结果范围不同，请注意适用的基金业务类型*/
/*编写人员：刘雨*/
/*联系方式：*/
/*编写日期：20241213*/ 
SELECT prod_cd as "基金代码"
       ,invs_mthd as "养老金类型"
       ,mohrss_id as "养老金代码"
       ,mohrss_pnsn_scrt_chn_fll_nm  as "养老金名称"
       ,fnct_crrn_hldn_mkt_vl as "市值"
       ,fnct_crrn_mkt_vl_rt as "占基金净值比例"
FROM dtlab_r.v_dwm_inv_prod_invs_pnsn_hldn_dtls
where vltn_dt= '20241212' AND /*输入日期时点*/
prod_cd= '800003'  /*输入产品代码*/
```

## 查询说明
此查询用于从数据库中提取特定基金在指定日期的养老金持仓信息。查询结果包括基金代码、养老金类型、养老金代码、养老金名称、市值和占基金净值的比例。

## 条件说明
- `vltn_dt`: 指定的估值日期，格式为YYYYMMDD。例如，20241212表示2024年12月12日。
- `prod_cd`: 基金代码，用于标识具体的基金产品。例如，800003。

## 业务场景
此查询适用于投资组合分析中的养老金持仓情况分析，帮助投资者或分析师了解特定基金在某一时间点的养老金投资分布情况。

## 问题说明
- 由于表的权限不同，查询结果可能因执行者的权限而异。
- 确保输入的日期和基金代码正确无误，以避免查询不到数据。

## 优化建议
- 定期检查和更新表的权限设置，确保查询结果的准确性和完整性。
- 对于频繁使用的查询，可以考虑创建视图或存储过程，提高查询效率。
- 在生产环境中，建议使用参数化查询，以增强安全性和灵活性。
