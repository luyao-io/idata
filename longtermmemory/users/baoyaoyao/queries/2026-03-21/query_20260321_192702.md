# QDII查询

## 查询目的
查询所有类型为QDII且属于公募基金的产品代码、产品层级、产品渠道简称以及份额货币。

## SQL查询
```sql
select 
    prod_cd, prod_lvl,
    prod_chns_abbr_rglt_rprt_60011,
    shr_crrn
from dtlab_r.v_dim_prod_dmns
where prod_typ_200272='QDII'
and prod_typ_203427='公募'
```

## 查询说明
此查询从`dtlab_r.v_dim_prod_dmns`视图中提取了特定条件下的产品信息。主要关注的是QDII类型的公募基金，包括其产品代码（`prod_cd`）、产品层级（`prod_lvl`）、产品渠道简称（`prod_chns_abbr_rglt_rprt_60011`）和份额货币（`shr_crrn`）。

## 条件说明
- `prod_typ_200272='QDII'`: 筛选出产品类型为QDII的产品。
- `prod_typ_203427='公募'`: 进一步筛选出属于公募基金的产品。

## 业务场景
在投资组合分析中，了解不同类型的基金产品对于构建和管理投资组合至关重要。特别是对于QDII（Qualified Domestic Institutional Investor，合格境内机构投资者）基金，这类基金允许国内投资者投资海外市场，因此对这些产品的详细信息进行查询有助于更好地理解和评估其在投资组合中的作用。
