# 基金经理管理经验年限划分逻辑

## 规则定义
基金经理管理经验年限划分逻辑用于将基金经理的实际管理年限转换为更易于理解的描述形式，以便于投资组合分析和报告。

## 业务规则
实际年限在x.0-x.1之间的写作 "x年"；实际年限在x.1（含）-x.5（含）之间的写作 "超x年"；实际年限大于x.5的写作 "近(x+1)年"。

## 计算规则
```sql
CASE 
    WHEN mng_prd - FLOOR(mng_prd) >= 0 AND mng_prd - FLOOR(mng_prd) < 0.1 THEN TO_CHAR(FLOOR(mng_prd)) || '年基金管理经验'
    WHEN mng_prd - FLOOR(mng_prd) >= 0.1 AND mng_prd - FLOOR(mng_prd) <= 0.5 THEN '超' || TO_CHAR(FLOOR(mng_prd)) || '年基金管理经验'
    ELSE '近' || TO_CHAR(CEILING(mng_prd)) || '年基金管理经验'
END AS fund_mng_exp
```

## 时间规则
无特定时间规则。

## 金额规则
无特定金额规则。

## 查询最佳实践
确保在计算基金经理管理经验时，使用准确的管理开始日期和当前日期进行计算，以获得最精确的结果。同时，建议定期更新数据，以反映最新的管理经验情况。
