# 基金净值数据查询权限问题

## 规则定义
当前用户无权访问dtlab_r模式下的表，需要系统管理员授权才能查询基金净值数据。

## 业务规则
在进行投资组合分析时，用户必须具有相应的权限才能访问基金净值数据。若用户尝试查询而未获得适当权限，将无法成功执行查询操作。

## 计算规则
```sql
-- 示例查询语句（需具备相应权限）
SELECT * FROM dtlab_r.fund_net_value WHERE fund_id = '12345';
```

## 时间规则
用户应在工作时间内联系系统管理员以请求权限，通常为工作日的9:00至18:00。

## 金额规则
此规则不涉及金额相关的内容。

## 查询最佳实践
1. 确认是否已获得访问基金净值数据的必要权限。
2. 如未获得权限，应通过正式渠道向系统管理员提交权限申请。
3. 在等待权限审批期间，可以先准备查询所需的SQL语句和其他准备工作。
4. 获得权限后，立即执行查询并记录结果，以便后续分析。
