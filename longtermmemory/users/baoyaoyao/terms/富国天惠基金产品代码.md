# 富国天惠基金产品代码

## 业务含义
富国天惠系列基金是一系列由富国基金管理有限公司管理的开放式基金，包括不同份额类别以满足投资者的不同需求。具体产品代码如下：
- 161005：富国天惠成长混合（LOF）A/B
- 003494：富国天惠成长混合（LOF）C
- 022645：富国天惠成长混合（LOF）D

## 数据库字段映射
- `fund_code`：基金产品代码
- `fund_name`：基金名称
- `share_class`：份额类别

## 计算公式
```sql
SELECT fund_code, fund_name, share_class
FROM fund_products
WHERE fund_name LIKE '富国天惠成长混合%';
```

## 分类说明
富国天惠系列基金根据不同份额类别（A/B、C、D）提供不同的投资策略和费用结构，以适应不同投资者的投资偏好和风险承受能力。
