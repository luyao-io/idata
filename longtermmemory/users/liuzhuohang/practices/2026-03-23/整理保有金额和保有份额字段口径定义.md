# 整理保有金额和保有份额字段口径定义

## 查询目的
整理并汇总不同渠道类型的保有金额和保有份额数据，区分货币基金和非货币基金，以便于营销管理和分析。

## SQL查询
```sql
SELECT 
  clnd_dt  as '确认日',
  case 
    when sll_chnn_abbr_0 = '富国直销' then '直销'
    when  sll_chnn_abbr_0 != '富国直销' then '三方'
  end as '渠道类型',   
  case 
    when prod_typ_200272 in ('货币') then '货币' 
    else '非货' 
  end as '货币或非货',
  sum(amnt_blnc_6) as '保有金额',
  sum(shr_blnc) as '保有份额'
from
 (select
   clnd_dt,
   sll_chnn_abbr_0,
   prod_typ_200272,
   sum(amnt_blnc_6)  as amnt_blnc_6,
   sum(shr_blnc)  as shr_blnc
   from dtlab_r.v_dws_mkt_all_chnn_hld_indx
   WHERE clnd_dt  between trunc(sysdate) -62 and trunc(sysdate) -1
       and clnd_dt = last_day(clnd_dt)
       and prod_typ_203427 ='公募'
       and cstm_typ = '个人'
       and sll_chnn_abbr_0 = '富国直销'
   GROUP by 1,2,3

  union all

  select 
    dat_dt,
    fnd_nm,
    fnd_typ,
    sum(hld_scl)  as amnt_blnc_6,
    sum(hld_shr)  as shr_blnc      
  from dtlab_r.v_t_thrd_prty_bsns_anly_bss
  WHERE dat_dt between trunc(sysdate) -62 and trunc(sysdate) -1
        and dat_dt = last_day(dat_dt)
        and dat_typ_cd='4'          
  group by 1,2,3
  ) as table2
group by 1,2,3
```

## 查询说明
此查询从两个不同的数据源中提取数据，一个是内部直销渠道的数据表 `v_dws_mkt_all_chnn_hld_indx`，另一个是第三方渠道的数据表 `v_t_thrd_prty_bsns_anly_bss`。通过 `UNION ALL` 将两个数据源的数据合并，并按确认日、渠道类型和基金类型（货币或非货）进行分组汇总，计算保有金额和保有份额。

## 条件说明
- 数据日期范围：过去两个月内（从当前日期往前推62天至前一天）。
- 确认日为每月最后一天。
- 产品类型为“公募”。
- 客户类型为“个人”。
- 内部直销渠道名称为“富国直销”。
- 第三方渠道的数据类型代码为“4”。

## 业务场景
此查询适用于营销管理分析，帮助了解不同渠道在不同基金类型上的保有情况，为后续的市场策略调整提供数据支持。

## 问题说明
- 确认日的筛选条件使用了 `last_day(clnd_dt)` 和 `last_day(dat_dt)`，确保只选取每月最后一天的数据。
- 渠道类型通过 `sll_chnn_abbr_0` 字段判断，分为“直销”和“三方”。
- 基金类型通过 `prod_typ_200272` 字段判断，分为“货币”和“非货”。

## 优化建议
- 考虑增加索引以提高查询性能，特别是在 `clnd_dt` 和 `dat_dt` 字段上。
- 对于大数据量的查询，可以考虑使用分区表来提高查询效率。
- 定期检查和更新统计信息，以确保查询优化器能够选择最优的执行计划。
