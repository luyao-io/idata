# 渠道实际保有(含客户类型版)查询

## 查询目的
查询特定日期（2025-04-06）证券公司的渠道实际保有情况，包括渠道名称、主产品代码、客户类型、渠道实际规模、渠道实际份额、户数及产品类型等信息。

## SQL查询
```sql
-- 由于权限限制，无法执行原查询
-- 原查询意图：查询渠道实际保有情况(含客户类型版)
select
  k1.日期,
  k1.渠道名称,
  k1.主产品代码,
  k2.产品名称,
  k1.客户类型,
  k1.渠道实际规模,
  k1.渠道实际份额,
  k1.户数,
  case
    when k2.产品名称 like '%ETF%'
    and k2.产品名称 not like '%联接%' then 'ETF'
    when k2.产品名称 like '%ETF%' then 'ETF联接'
    else k2.prod_typ_200272
  end as '产品类型'
from
  (
    SELECT
      a.clnd_dt AS '日期',
      a.sll_chnn_abbr_0 AS '渠道名称',
      replace (mn_prod_cd, '+0', '') as '主产品代码',
      a.cstm_typ as '客户类型',
      sum(a.amnt_blnc_4) as '渠道实际规模',
      sum(a.shr_blnc) as '渠道实际份额',
      count(cstm_srrg_key) as '户数'
    from
      dtlab_r.v_dws_mkt_all_chnn_hld_indx a
      left join dtlab_r.v_s060_crm_r_vecif_jgzhlb b on b.jyzh = a.trd_acct
      and b.xsjg = a.sll_chnn_cd_0
    where
      a.clnd_dt = '2025-04-06'
      and b.zhmc is null
      and a.sll_chnn_typ = '证券公司'
    GROUP BY
      a.clnd_dt,
      a.cstm_typ,
      a.sll_chnn_abbr_0,
      a.sll_chnn_typ,
      a.prod_abbr,
      a.mn_prod_cd,
      a.prod_typ_200272
  ) k1
  left join (
    select distinct
      prod_cd,
      prod_chn_abbr_intr_use_200136 as '产品名称',
      prod_typ_200272
    from
      dtlab_r.v_dim_prod_dmns
    where
      prod_lvl = '0'
  ) k2 on k1.主产品代码 = k2.prod_cd
```

## 查询说明
此查询旨在从`dtlab_r.v_dws_mkt_all_chnn_hld_indx`和`dtlab_r.v_dim_prod_dmns`两个视图中提取数据，计算并展示特定日期证券公司的渠道实际保有情况。查询结果包括日期、渠道名称、主产品代码、客户类型、渠道实际规模、渠道实际份额、户数以及根据产品名称分类的产品类型。

## 条件说明
- `a.clnd_dt = '2025-04-06'`：指定查询的日期为2025年4月6日。
- `b.zhmc is null`：排除已知账户名称的数据。
- `a.sll_chnn_typ = '证券公司'`：仅考虑证券公司类型的渠道。
- `prod_lvl = '0'`：在产品维度表中选择顶级产品。

## 业务场景
此查询适用于市场营销管理分析中的渠道保有量分析，帮助了解不同渠道在特定时间点上的客户持有情况，特别是针对证券公司这一特定渠道类型。
