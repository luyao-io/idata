# 渠道实际保有产品量查询

## 查询目的
查询特定渠道在指定日期范围内的实际保有产品量，并区分账户类型（渠道或机构）。

## SQL查询
```sql
-- 由于权限限制，无法执行原查询
-- 原查询意图：查询渠道实际保有产品量
select
  a.clnd_dt as '自然日期',
  a.sll_chnn_abbr_0 as '渠道名称',
  a.mn_prod_nm as '产品名称',
  sum(a.amnt_blnc_2) as '保有量',
  case
    when b.ZHMC is null then '渠道'
    else '机构'
  END AS '账户类型'
from
  dtlab_r.v_dws_mkt_all_chnn_hld_indx a
  left join dtlab_r.v_s060_ecif_vecif_jgzhlb b on b.jyzh = a.trd_acct
  and b.xsjg = a.sll_chnn_cd_0
  left join dtlab_r.v_s060_ecif_tjj_jgkhkzxx_jgkh c on c.id = b.khgs
where
  a.clnd_dt between '2023-12-25' and '2024-07-28'
  and a.sll_chnn_abbr_0 ='中金财富证券'
  and a.mn_prod_nm = '富国洞见价值股票型证券投资基金'
  and case
    when b.ZHMC is null then '渠道'
    else '机构'
  END = '渠道'
group by a.clnd_dt,a.sll_chnn_abbr_0,a.mn_prod_nm,b.ZHMC
order by
  a.clnd_dt DESC
```

## 查询说明
此查询旨在从`dtlab_r.v_dws_mkt_all_chnn_hld_indx`表中获取特定渠道在指定日期范围内的产品保有量数据。通过与`dtlab_r.v_s060_ecif_vecif_jgzhlb`和`dtlab_r.v_s060_ecif_tjj_jgkhkzxx_jgkh`表进行左连接，以确定账户类型（渠道或机构）。最终结果按自然日期降序排列。

## 条件说明
- `a.clnd_dt between '2023-12-25' and '2024-07-28'`: 指定查询的日期范围为2023年12月25日至2024年7月28日。
- `a.sll_chnn_abbr_0 ='中金财富证券'`: 限定查询的渠道为“中金财富证券”。
- `a.mn_prod_nm = '富国洞见价值股票型证券投资基金'`: 限定查询的产品为“富国洞见价值股票型证券投资基金”。
- `case when b.ZHMC is null then '渠道' else '机构' END = '渠道'`: 仅选择账户类型为“渠道”的记录。

## 业务场景
此查询适用于市场营销管理分析中的渠道绩效评估，帮助了解特定渠道在一定时间范围内对特定产品的销售和保有情况。
