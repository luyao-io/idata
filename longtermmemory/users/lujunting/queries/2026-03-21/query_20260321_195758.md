# 代销渠道跟踪查询

## 查询目的
此查询旨在跟踪特定日期（2024-04-30）的代销渠道的保有量、渠道保有量及较上年末的增长情况。通过分析这些数据，可以帮助营销管理人员了解各渠道的表现，从而做出更有效的市场策略调整。

## SQL查询
```sql
-- 由于权限限制，无法执行原查询
-- 原查询意图：代销渠道跟踪
SELECT
  a.clnd_dt AS '日期',
  a.sll_chnn_abbr_0 AS '渠道名称',
  a.sll_chnn_typ AS '渠道类型',
  sum(a.amnt_blnc_4) AS '期末保有',
  SUM(
    CASE
      WHEN b.ZHMC is null
      THEN a.amnt_blnc_4
      ELSE 0
    END
  ) AS '渠道保有',
 sum(a.amnt_blnc_4)-SUM(
      CASE
        WHEN a.clnd_dt = DATE (CONCAT (YEAR (a.clnd_dt), '-01-01')) THEN amnt_blnc_4
        ELSE 0
      END
    )
   AS '较上年末增长'
from
  dtlab_r.v_dws_mkt_all_chnn_hld_indx a
  left join dtlab_r.v_s060_ecif_vecif_jgzhlb b on b.jyzh = a.trd_acct
  and b.xsjg = a.sll_chnn_cd_0
where
  a.clnd_dt ='2024-04-30'
GROUP BY
  a.clnd_dt,
  a.sll_chnn_abbr_0,
  a.sll_chnn_typ
```

## 查询说明
该查询从`dtlab_r.v_dws_mkt_all_chnn_hld_indx`表中提取了指定日期的代销渠道数据，并通过左连接`dtlab_r.v_s060_ecif_vecif_jgzhlb`表来获取额外的渠道信息。查询结果包括日期、渠道名称、渠道类型、期末保有量、渠道保有量以及与年初相比的增长量。

## 条件说明
- `a.clnd_dt = '2024-04-30'`: 指定查询的日期为2024年4月30日。
- `b.jyzh = a.trd_acct AND b.xsjg = a.sll_chnn_cd_0`: 用于连接两个表的条件，确保交易账户和销售机构代码匹配。

## 业务场景
此查询适用于营销管理分析中的渠道表现评估，特别是在需要定期检查不同销售渠道的业绩时。通过这些数据，管理层可以识别表现优异或不佳的渠道，进而采取相应的策略进行优化或调整。
