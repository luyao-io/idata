# 年金资金跟踪查询

## 查询目的
此查询旨在跟踪特定时间段内（2024年4月1日至2024年4月30日）的企业年金和职业年金的资金流动情况，包括资金流入、资金流出、净流入以及保有规模和保有份额。

## SQL查询
```sql
-- 由于权限限制，无法执行原查询
-- 原查询意图：年金资金跟踪
select
  prtf_cd,
  prtf_nm,
  prtf_typ,
  t2.name as '销售',
  (case when t3.name='养老金业务四组' then '养老金业务一组' else t3.name end) as '团队',
  sum(tdy_infl) as '资金流入',
  sum(tdy_otfl) as '资金流出',
  sum(tdy_infl)-sum(tdy_otfl) as '净流入',
  sum(case when dt_dt ='2024-04-30' then tdy_scl else 0 end) as '保有规模' ,
  sum(case when dt_dt ='2024-04-30' then tdy_shr else 0 end) as '保有份额'
from
  dtlab_r.v_t_non_mtl_fnd_mkt_dat a
  left join dtlab_r.v_s060_crm_r_vecif_jgzhlb b on b.jjzh = a.prtf_cd
  left join dtlab_r.v_s060_ecif_tjj_jgkhgx t1 on b.id =t1.khh and t1.zt='0'
  left join dtlab_r.v_s060_ecif_tjj_jgkhkzxx_jgkh c on c.id = b.khgs
  left join dtlab_r.v_s060_jjcrm_tuser t2 on t1.ryxx = t2.id
  left join dtlab_r.v_s060_jjcrm_lborganization t3 on t2.orgid = t3.id  
where
  dt_dt between '2024-04-01' and '2024-04-30'
and  prtf_typ in ('企业年金','职业年金')
group by
  prtf_cd,
  prtf_nm,
  prtf_typ,
  t2.name,
  t3.name
```

## 查询说明
该查询从多个视图中提取数据，通过联接操作整合了基金代码、基金名称、基金类型、销售人员、所属团队等信息，并计算了指定日期范围内的资金流入、资金流出、净流入以及截至2024年4月30日的保有规模和保有份额。

## 条件说明
- `dt_dt between '2024-04-01' and '2024-04-30'`：限定查询的时间范围为2024年4月1日至2024年4月30日。
- `prtf_typ in ('企业年金','职业年金')`：限定查询的基金类型为企业年金和职业年金。

## 业务场景
此查询适用于市场营销管理分析中的年金产品跟踪，帮助管理层了解不同团队在特定时间段内的业绩表现，以及各年金产品的市场表现。
