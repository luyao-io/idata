# ETF账户持有人信息查询

## 查询目的
查询ETF账户持有人的相关信息，包括持有人姓名、产品名称、收益权重、规模、公司名称、销售人员、销售团队及CRM业务类型。

```sql

select
  m.cstm_nm,
  m.prod_nm,
  case
        when t1.syqz is null then 1
        else t1.syqz / 100
      end as '收益权重',
  sum(m.hld_amount*(case
        when t1.syqz is null then 1

      end)) as '规模',
  c.gsmc as '公司名称',
  t2.name as '销售',

 left join dtlab_r.v_s060_crm_r_vecif_jgzhlb b on b.jjzh = m.fnd_acct  and b.xsjg=m.sll_chnn_cd_0
 left join dtlab_r.v_s060_ecif_tjj_jgkhkzxx_jgkh c on c.id = b.khgs
  left join dtlab_r.v_s060_ecif_tjj_jgkhgx t1 on b.id = t1.khh
  and t1.zt = '0'
  left join dtlab_r.v_s060_jjcrm_tuser t2 on t1.ryxx = t2.id
  left join dtlab_r.v_s060_jjcrm_lborganization t3 on t2.orgid = t3.id
  where b.zhmc is not null
  group by 
  m.cstm_nm,
  m.prod_nm,
  c.gsmc ,
  t2.name,
  t3.name ,
  t1.syqz
```

## 查询说明
此查询旨在从多个表中提取ETF账户持有人的信息，并计算每个持有人的收益权重和规模。查询结果将帮助营销管理人员更好地了解客户分布和销售情况。

## 条件说明
- `m.cstm_nm`: 持有人姓名
- `m.prod_nm`: 产品名称
- `t1.syqz`: 收益权重，如果为空则默认为1
- `m.hld_amount`: 持有量
- `c.gsmc`: 公司名称
- `t2.name`: 销售人员姓名
- `t3.name`: 销售团队名称
- `b.zhmc is not null`: 确保账户名称不为空
