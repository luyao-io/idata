# 区域保有测试查询

## 查询目的
此查询旨在分析特定日期（2024年11月12日）的区域保有数据，包括客户数量、当日规模、期末规模等指标，并结合不同渠道和产品的权重进行综合评估。

```sql

select
  a.dat_dt,
  a.prov,
  a.cty,
  a.chnn_cd,
  a.prod_cd,
  m.branchname,
  m.channelname,
  m.c_areaname,
  m.name,
  m.权重,
  m.权重处理后,
  case
    when A.dat_dt = date ('20241112') then m.权重
    else 0
  end as '期末的权重',
  sum(
    case
      when A.dat_dt = date ('20241112') then a.cstm_qntt
      else null
    end
  ) as '期末客户数',
  sum(a.chnn_hld_amnt) * m.权重处理后 as '权重后当日规模',
  sum(a.cstm_qntt) as '客户数',
  sum(a.chnn_hld_amnt) as '当日规模',
  sum(
    case
      when A.dat_dt = date ('20241112') then a.chnn_hld_amnt * m.权重处理后
      else 0
    end
  ) as '期末规模',
  sum(
    case
      when A.dat_dt = date ('20241112') then a.chnn_hld_amnt * m.权重处理后
      else 0
    end
  ) - sum(
    case
      when A.dat_dt = date ('20240101') then a.chnn_hld_amnt * m.权重处理后
      else 0
    end
  ) as incr_amnt
from
  dtlab_r.v_t_orgn_ln_cmpr_dat a
  left join (
    select distinct
      a1.branchfullname,
      a1.branchname,
      a1.channelname,
      a1.citycode,
      b.c_areaname,
      c.salemanager,
      c.saleagencycode,
      t2.name,
      c.proportion / 100 as '权重',
      case
        when c.proportion is null then cast(100 / 100 as VARCHAR)
        else cast(c.proportion / 100 as varchar)
      end as '权重处理后'
    from
      dtlab_r.v_s060_jjcrm_tjj_qd_qygx a1
      left join dtlab_r.v_s068_standdb_tareainfotree b on b.c_gbcode = a1.citycode
      left join dtlab_r.v_s060_jjcrm_tjj_qd_xsfhgx c on a1.channelname = c.channelname
      and c.branchname = a1.branchname
      left join dtlab_r.v_s060_jjcrm_tuser t2 on c.salemanager = t2.userid
    where
      a1.channeltype = '2'
        and a1.status='1'
       and c.status='1'
  ) as m on a.chnn_cd = m.saleagencycode
  and a.cty_cd = m.citycode
where
  (
    dat_dt between '20241112'
    and  '20241112'
  )
group by
  a.dat_dt,
  a.prov,
  a.cty,
  a.chnn_cd,
  a.prod_cd,
  m.权重,
  m.权重处理后,
  m.branchname,
  m.channelname,
  m.c_areaname,
  m.name
```

## 查询说明
该查询通过连接多个视图来获取区域保有数据，并计算了不同日期的客户数量、当日规模、期末规模等关键指标。特别地，查询中使用了权重和处理后的权重来调整计算结果，以反映不同渠道和产品的重要性。

## 条件说明
- `dat_dt between '20241112' and '20241112'`：限定查询日期为2024年11月12日。
- `a1.channeltype = '2'`：限定渠道类型为2。
- `a1.status = '1'` 和 `c.status = '1'`：确保相关记录的状态为有效。
