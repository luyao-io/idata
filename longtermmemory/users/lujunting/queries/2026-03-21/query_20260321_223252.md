# 首购用户查询

## 查询目的
分析证券公司渠道的首购用户情况，包括首购客户数、首购客户客单价、券商渠道客户数净增量及券商渠道客户客均保有规模。

## SQL查询
```sql
-- 由于权限限制，无法执行原查询
-- 原查询意图：分析证券公司渠道的首购用户情况
with
  tmp as (
    select
      row_number() over (
        partition by
          prod_cd,
          aftr_mrg_cstm_id,
          sll_chnn_abbr_0
        order by
          clnd_dt
      ) rn,
      prod_cd,
      sll_chnn_abbr_0,
      aftr_mrg_cstm_id,
      clnd_dt,
      amnt_blnc_4
    from
      dtlab_r.v_dws_mkt_all_chnn_hld_indx
    where
      clnd_dt <= date '2024-08-02'
      and clnd_dt >= date '2020-01-01'
      and sll_chnn_typ = '证券公司'
      and prod_cd in (
        '510210',
        '512040',
        '512710',
        '561120',
        '513870',
        '513350',
        '159971',
        '159825',
        '159766',
        '159792',
        '159629',
        '159506',
        '159350',
        '159300'
      )
  ),
  tmp1 as (
    select
      prod_cd,
      clnd_dt,
      sll_chnn_abbr_0,
      round(sum(amnt_blnc_4) / count(aftr_mrg_cstm_id), 2) n_unit,
      count(aftr_mrg_cstm_id) n_count
    from
      tmp t
    where
      clnd_dt <= date '2024-08-02'
      and clnd_dt >= date '2024-07-08'
      and rn = 1
    group by
      prod_cd,
      clnd_dt,
      sll_chnn_abbr_0
  ),
  tmp2 as (
    select
      clnd_dt,
      prod_cd,
      sll_chnn_abbr_0,
      n_count,
      n_unit
    from
      tmp1
    order by
      clnd_dt
  ),
  tmp3 as (
    select
      prod_cd,
      clnd_dt,
      sll_chnn_abbr_0,
      prod_abbr,
      count(distinct aftr_mrg_cstm_id) as n_count_id,
      sum(amnt_blnc_4) / count(distinct aftr_mrg_cstm_id) as avg_val
    from
      dtlab_r.v_dws_mkt_all_chnn_hld_indx
    where
      clnd_dt <= date '2024-08-02'
      and clnd_dt >= date '2024-07-08'
      and prod_cd in (
        '510210',
        '512040',
        '512710',
        '561120',
        '513870',
        '513350',
        '159971',
        '159825',
        '159766',
        '159792',
        '159629',
        '159506',
        '159350',
        '159300'
      )
      and sll_chnn_typ = '证券公司'
    group by
      prod_cd,
      clnd_dt,
      sll_chnn_abbr_0,
      prod_abbr
    order by
      clnd_dt
  ),
  tmp4 as (
    select
      prod_cd,
      clnd_dt,
      sll_chnn_abbr_0,
      prod_abbr,
      count(distinct aftr_mrg_cstm_id) as n_count_id
    from
      dtlab_r.v_dws_mkt_all_chnn_hld_indx
    where
      clnd_dt <= date '2024-08-01'
      and clnd_dt >= date '2024-07-07'
      and prod_cd in (
        '510210',
        '512040',
        '512710',
        '561120',
        '513870',
        '513350',
        '159971',
        '159825',
        '159766',
        '159792',
        '159629',
        '159506',
        '159350',
        '159300'
      )
      and sll_chnn_typ = '证券公司'
    group by
      prod_cd,
      clnd_dt,
      sll_chnn_abbr_0,
      prod_abbr
  )
select
  t1.clnd_dt as '日期',
  t1.sll_chnn_abbr_0 as '渠道',
  t1.prod_abbr as '产品',
  t2.n_count as '首购客户数',
  t2.n_unit as '首购客户客单价',
  t1.n_count_id - t.n_count_id as '券商渠道客户数净增量',
  t1.avg_val as '券商渠道客户客均保有规模'
from
  tmp3 t1
  left join tmp4 t on t1.prod_cd = t.prod_cd
  and t1.clnd_dt = t.clnd_dt + 1
  and t1.sll_chnn_abbr_0 = t.sll_chnn_abbr_0
  left join tmp2 t2 on t1.clnd_dt = t2.clnd_dt
  and t1.prod_cd = t2.prod_cd
  and t1.sll_chnn_abbr_0 = t2.sll_chnn_abbr_0
order by
  t1.prod_cd,
  t1.clnd_dt
```

## 查询说明
此查询通过多个临时表（`tmp`, `tmp1`, `tmp2`, `tmp3`, `tmp4`）来逐步处理数据，最终计算出每个产品的首购客户数、首购客户客单价、券商渠道客户数净增量及券商渠道客户客均保有规模。查询结果按产品代码和日期排序。

## 条件说明
- `clnd_dt`：日期范围为2020年1月1日至2024年8月2日。
- `sll_chnn_typ`：销售渠道类型为“证券公司”。
- `prod_cd`：产品代码列表包括'510210', '512040', '512710', '561120', '513870', '513350', '159971', '159825', '159766', '159792', '159629', '159506', '159350', '159300'。
