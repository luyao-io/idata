# 查询公募产品择时收益率

## 查询目的
计算特定时间段内公募产品的择时收益率，以评估其市场表现。

## SQL查询
```sql
-- 由于权限限制，无法执行原查询
-- 原查询意图：计算公募产品的择时收益率
select
  prod_abbr,
  prod_cd,
  sum(t.总收益) as '总收益',
  sum(t.期初规模) as '总规模',
  sum(t.平均净流入和盈亏) as '平均净流入和盈亏',
  sum(t.总收益) / (sum(t.期初规模) + sum(t.平均净流入和盈亏)) as '择时收益率'
from
  (
    select
      prod_abbr,
      prod_cd,
      sum(tdy_prft_lss) as '总收益',
      case
        when clnd_dt = '20250101' then sum(tdy_hld_amnt)
        else 0
      end as '期初规模',
      365 - DATEDIFF ('day', '20250101', clnd_dt) AS 持有天数,
      sum(tdy_infl - tdy_otfl ) as '净流入和盈亏',
      (sum(tdy_infl - tdy_otfl ) * 持有天数) / 365 as '平均净流入和盈亏'
    from
      dtlab_r.v_t_orgn_cstm_prft_dat
    where
      clnd_dt between '20250101' and '20250530'
      and prod_typ_203427 = '公募'
    group by
      clnd_dt,
      prod_abbr,
      prod_cd
  ) t
group by
  prod_abbr,
  prod_cd
```

## 查询说明
此查询旨在通过计算公募产品的总收益、期初规模、平均净流入和盈亏等指标，进一步得出择时收益率。由于当前用户无权限访问`dtlab_r.v_t_orgn_cstm_prft_dat`表，该查询无法执行。

## 条件说明

- `prod_typ_203427 = '公募'`: 仅选择产品类型为“公募”的记录。
