# 保有规模查询规则

## 规则定义
保有规模是个时点值，通常使用区间的最后一天的时点值。在查询特定时间段的保有规模时，应选择该时间段最后一天的数据作为代表值，而非对整个时间段进行平均或其他聚合计算。

## 业务规则
在营销管理分析中，保有规模的查询应严格遵循时点值的原则，即使用特定时间段的最后一个时间点的数据来表示该时间段的保有规模。

## 计算规则
```sql
SELECT scale_value
FROM holding_scale
WHERE date = (SELECT MAX(date) FROM holding_scale WHERE date BETWEEN 'start_date' AND 'end_date')
```

## 时间规则
查询特定时间段的保有规模时，应确保所选日期为该时间段的最后一天。

## 金额规则
保有规模的金额值应直接取自区间的最后一天，不进行任何形式的调整或聚合。

## 查询最佳实践
- 确定查询的时间段，并明确该时间段的最后一天。
- 使用SQL查询语句，从数据库中提取该时间段最后一天的保有规模数据。
- 避免对时间段内的数据进行平均或其他形式的聚合计算，以保持数据的准确性和一致性。
